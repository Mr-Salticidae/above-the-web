01Who

这是谁的站

跳蛛先生，GitHub 上叫 Mr-Salticidae。做 AI 图像、视频与音乐的创作者，也带学员做项目。 2026 年 5 月起，把每次创作探索里「学到了什么」沉淀成一份公开的知识库；6 月底把它搬上网， 这就是「蛛网之上」最初的样子。此后两个月，它长出了每天更新的快讯、一期期 prompt 拆解、 几件能直接上手玩的小作品、对外的任务书，和自己做的歌。

跳蛛是不结网捕食的蜘蛛，靠一双好眼睛和一跃。站名里的「网」是互联网的网： 把值得留下的，都织在这张网上。

03Principles

这站的几条规矩

  1. 读站不需要账号。快讯、笔记、Prompt 大师、可玩、音乐一律不拦。只有认领任务书要登录， 因为那头连着报酬和打款，得能把人对上。
  2. 不埋统计脚本，不放广告。页面里没有任何第三方追踪；你来过、看了什么，站长不知道，也不想知道。
  3. 宁缺毋滥。快讯每天只留值得创作者看的那几条，凑数的不发；笔记只收有 insight 的发现， 产出本身不归档。
  4. 记录过程，不只晒结果。Prompt 大师每期讲清「难在哪、怎么破题」；获奖图和翻车都写复盘， 放在笔记里。
  5. 网上没有的丝，不凭空织。站内的 AI 查笔记只依据已发布的笔记作答，每条结论带来源； 资料不足就直说，不用站外常识补齐。
  6. 内容开源，源码公开。知识库与站点代码都在 GitHub，出了问题可以直接看到是怎么修的。

05Colophon

这站怎么做的

全部踩坑都记在笔记的「平台工程」栏目， 源码在 GitHub ↗。

框架
Astro 5 静态生成，页面里没有前端框架。Obsidian 的 [[双链]] 由自写的 remark 插件在构建期解析成站内链接。
内容
构建时浅克隆 knowledge-base 与 becoming-a-prompt-master 两个公开仓库，按栏目白名单进站；快讯一天一份 JSON 存在本仓库。
搜索
Pagefind 静态全文索引，随产物一起发布，没有后端。
排版
宋体标题配无衬线正文，全部走系统字体、不下载 webfont。昼夜双皮肤，首页那张蛛网是 canvas 现画的。
自动化
GitHub Actions 每早抓取 RSS 候选，再用一次结构化调用选稿写摘要；单次成本约一毛钱。站点每 6 小时兜底重建一次。
部署
同一次构建出三份产物：GitHub Pages 镜像、香港服务器（国内主入口）、快讯子站。
账号
Node + node:sqlite 的一个小服务，只管登录、认领与流转；读站的部分完全静态。
AI 的位置
小作品多是 vibe coding；快讯选稿、任务书草稿、小织答疑各接一个模型。判断与取舍留给人。
