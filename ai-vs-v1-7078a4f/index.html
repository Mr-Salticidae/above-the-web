AI 甜妹脸 vs 复古东方美人

首次沉淀:2026-05-01(02 教程失败组对比实测) 入档:2026-05-02 主线作品来源:02_角色一致性锚点/02_角色卡.md(实测结论修正章节)

一句话总结

MJ V7+ base model 默认输出的不是”中国脸”,是西方训练集对东方面孔的”复古化想象”——民国老照片质感的东方美人,而非当代东方审美。personalize 才能修正这个偏差。

如何使用

✅ 作为内容素材:这是 02 教程最稀缺的批判性视角 ✅ 作为 personalize 价值的论据:具体数据证明 personalize 不是可选,是必备 ✅ 作为 IP 战略思考:中国创作者用 AI 时,必须 personalize 才能”夺回审美话语权”

⚠️ 写公开内容时的安全表述:用”训练集偏差”、“复古化想象”,避免”歧视/刻板印象/AI 殖民”等可能被算法定性为民族情绪向的词。

核心洞察

A 组的脸不是”AI 出错”,是 MJ 训练集(西方主导)对”east asian woman”的复古再现——西方眼里的”东方美人”原型。

类似:

  • 老月份牌女郎
  • 好莱坞经典电影里的中国小姐(Madame Butterfly 类型)
  • 1930s-1950s 时尚摄影里的”东方美人”

B 组才是用户 personalize 训练后真正学到的”用户的审美偏好”——更立体、更现代、更东方主体性。

战略含义

1 · personalize 不是可选,是必备

如果你的目标受众是当代中国人(包括跳蛛先生的小红书定位), 不开 personalize 输出的脸,你的目标受众会觉得”奇怪”—— 即使他们说不出哪里奇怪,但会有距离感。 距离感 = 完播率/收藏率下降 = 算法负反馈。

2 · 中国创作者的”审美主权”问题

“AI 不是没有审美——它有审美,但是别人的审美。 Personalize 是创作者夺回审美主权的方式。”

这句话有力,且不挑衅—— 它没有指控西方,只是揭示了一个结构性事实,然后给出积极的解法(用 personalize 重建主体性)。

3 · 这是 02 教程最高维的内容

原 02 是”教 oref/seed/描述词”——技巧贴。 加上这层观察后,02 升级成有思辨深度的作品—— 从”如何使用 AI” 上升到”和 AI 协作时,谁定义美”。

核心节奏:呈现差异 → 给出工具(personalize / moodboard)→ 鼓励中国创作者建立自己的审美体系。不批判,只赋能。

顶层金句段

“AI 不是没有审美——它有审美,但是别人的审美。 Personalize 是创作者夺回审美主权的方式。”

“我以为不开 personalize 会出欧美脸—— 实测后发现,它出的是民国老照片里的中国脸。 那不是种族识别错误,是西方训练集对东方面孔的’复古化想象’。 Personalize 让我把’她’拉回当代。“

双盲实验级证据(2026-05-03 V4 修复 R2)

R2 实验意外得到天然双盲对照——

  • 同 prompt + 同 moodboard,唯一变量 personalize 开/关,各跑 8 张
  • 结果:
    • personalize 开 → 8/8 清冷少女(唇色自然 / 瞳色正常 / 含蓄表情 / 少女年龄感)
    • personalize 关 → 8/8 复古东方美人陷阱(深酒红唇 / 红茶色瞳 / 妩媚成熟 / 25-30 年龄感)
  • 几何拓扑两组一致(头微低 + 看镜头 + 湿润),但气质天差地别

这是本档案描述的”复古东方美人”陷阱的双盲实验级证据—— 比之前”裸跑就出复古东方美人”的观察多了”开 moodboard 也救不回来”这个增量证据: moodboard 救不了 personalize 的缺位(因为它们管不同维度——见 personalize与moodboard分工_v1 修正四)。

实操升级:personalize 强制开,任何”清冷少女”题材都不可关—— 之前 checklist 里写”默认开”,现在升级为”强制开”。

二次验证增量：复古东方美人也可被纯文字主动调用（2026-06-13）

来源:2026-06-13_浴缸沐浴东方美人_Portra胶片人像复盘_v1(浴缸沐浴东方美人,接单产出,无 personalize / 无参考图,一次抽卡即得)。

本档原本把”复古东方美人”定义为 personalize 缺位下的偏差陷阱(要避)。该案例提供反向增量:

  • 同一个机制,换个场景就从”陷阱”变成”可用资产”。当目标受众不是当代小红书甜妹、而是时尚胶片 / 接单产出时,这套复古东方美人质感可以靠纯文字稳定主动调用。
  • 触发配方:porcelain skin with natural crimson + dark brown pupils + light rose matte lips + cold and ethereal elegant temperament + 胶片色卡(Portra 400)。无需 personalize 即可一次成型。
  • 判断口诀:先问”我要的是当代审美还是复古胶片质感”——要当代甜妹就开 personalize 并避开这套词;要复古胶片就大胆堆。
  • 边界:这套词出来的脸偏 25-30 岁成熟妩媚,做”清冷少女 / 低龄感”会偏老。

验证状态:机制二次验证 ⭐⭐(原档双盲证明该原型存在且 personalize 可修正;本次证明它也能被纯文字稳定主动调用)。

边界补充：本档结论目前只在女性侧成立（2026-08-05）⚠️

来源:2026-08-05_三角色校园人像定妆_MJ复盘_v1(同一天、同一 profile、三个角色)。

本档的双盲证据(8/8)与”personalize 强制开”的结论,样本全部是女性面孔。三角色定妆那次提供了男性侧的第一个观察:

personalize 开着时的表现
女性侧(女主 + 女配)✅ 都没掉进复古东方美人陷阱,出的是当代中国审美——印证本档结论
男性侧(男主 V1)⚠️ 仍出韩系男团脸,profile 没能阻止这个倾向
旁证三个角色的唇都偏红润带光泽——同一个 personalize 签名跨性别生效,但在女性侧是资产、在男性侧是负债(把”薄唇寡言”撑成了偶像唇)

假说:personalize 的训练集可能存在性别覆盖不均——喂进去的女性图多、男性图少,弱覆盖的一侧就退回 base model 或被弱偏好带偏。作者会误以为”profile 开着就都受保护”。

⚠️ 未验证:那次没有跑关 profile 的对照 A/B,不能当结论用。验证方法:同一条男性 prompt,带 profile / 关 profile 各跑 4 张背靠背,排除时机干扰。

在验证之前的操作口径:男性题材不要把”profile 开着”当成审美方向已受控的理由,该正面压制的还得正面压制(见 男性五官堆叠基础句_v1 的发型层与 --no 写法)。

第三次证据 + 一条新边界：默认落点要先分资产 / 负债（2026-08-20）

来源：2026-08-20_雨里旧信_东方美人封面四轮复盘_v1（1940s 老上海爵士唱片封面）。

正向证据（本档”可主动调用”结论 +1）：无 personalize、无参考图，纯文字堆本档记录的触发配方（瓷肌血色 + 深棕潮湿瞳 + matte 唇 + 气质层）即稳定得到复古东方美人原型，与 2026-06-13 两例同构。本档”复古东方美人可被纯文字主动调用”由此获得第三个数据点。

新边界（本档结论的一个易踩坑）：该案第一版反过来做了——预判”1940s 上海 + 旗袍 + 女人”会滑向月份牌美人，于是把 pin-up / advertisement poster / calendar girl 写进 --no 压制。

而本档记录的正是：MJ 对 east asian woman 的默认落点就是”老月份牌女郎”——那恰恰就是 1940s 老上海。压制它 = 自己拆掉唯一能免费拿到年代感的机制。

判据补充：本档原有的口诀是”先问要当代审美还是复古胶片质感”。该案说明还要再往前一步——

预判默认落点 → 【先分类：对本题材是资产还是负债】→ 只对负债接种

尤其注意：很多时候你反感的只是默认落点的某个维度（太甜 / 太艳 / 正面朝镜头笑），不是它的身份。这时该用气质层去调取向（本案用 melancholic 把甜艳扭成疏离忧郁），而不是整词压掉。

已独立成档：默认落点的资产负债判断_v1（⚠️ 首次发现），给 获奖图复盘方法论合集_活合集 第 40 条「负面词的预防式接种」划边界。

第四次证据 + 一条待验证的反向推论（2026-08-24）⚠️ 含当日自我更正

来源：2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘_v1（二十八宿星官，古典神话人物 + 黑底辉光中式插画）。

正向证据（本档「可主动调用」结论 +1，第四个数据点）✅：无 personalize、无 moodboard、无 --no 参数（末尾只有自然语言 no xxx），作者自述全默认（实际只设了 --ar 9:16），一版即得标准复古东方美人——丹凤眼、垂眸、橙红唇、鹅蛋脸、古典气度。与 2026-06-13 两例、2026-08-20 一例同构。

且这次落在中式插画词系（前三例均为写实胶片人像），初步说明该默认落点不挑画种 ⚠️ 单样本待复验。

反向推论（🔬 未验证）：personalize与moodboard分工_v1 修正四把 checklist 升级为「personalize 强制开」，其场景是当代清冷少女——personalize 的作用是把脸从复古原型拉回当代。由此推论：当题材要的就是复古原型时，这个作用方向是反的。

现有口径：personalize 强制开（女性侧）
待验证的细化：先问「我要的脸是不是 base model 的默认落点」
              是 → 先试裸跑（✅ 已证可行、成本低）
              否 → 开 personalize（原结论不变）

⚠️ 本节初版曾把这条推论写成实测结论，依据是同轮一批”加 personalize 后脸变当代少女”的出图。当晚核对作者实际 prompt 后发现那批跑的不是星官 prompt，而是一条当代清冷少女 prompt——它出当代少女脸是完全正确的执行，不是 personalize 破坏了古典味。该证据已作废，作废经过见 moodboard主体位判据_假说_v1。

当日晚间补上了受控样本（合挂形态）⭐：昴日鸡 prompt 逐字相同、seed 配对，唯一变量 --profile qwksp9b dsdxtdr（personalize ＋ 美女写真 moodboard 合挂）。挂了的 7/7：脸从垂眸丹凤的古典画中人变成立体五官、正红唇、有直视镜头的当代真人——「开着会破坏古典味」在合挂形态下成立。详见 2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘_v1。

⚠️ 两个未隔离：一是 personalize 与 moodboard 合挂，脸的切换归谁未分离；二是同批画种整个从插画翻转成了摄影，脸变当代可能只是画种翻转的自然结果（照片里的脸当然是真人脸）。所以「personalize 单独就会破坏复古原型」仍是 🔬——隔离方法：--profile qwksp9b 单挂一个 job 对比。决策层不受影响：要复古原型的题材，整条尾巴别挂，裸跑即得。

这条与 默认落点的资产负债判断_v1 是同一个判断落在不同工具上：那条说别把正确的默认落点写进 --no，这条说别用 personalize 把正确的默认落点拉走。两处的失误形状一样——预判到模型会往某个方向跑就本能去压制，而那个方向恰好是你要的。（⚠️ 本条同样只是推论。）
