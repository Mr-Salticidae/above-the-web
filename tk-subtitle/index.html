它解决什么 / what it fixes

语音识别吐出来的字幕，一条能有两三行长；手动断句断到眼花，还常常一不小心把内容删了自己都不知道。这个工具做一件事：按剪映里那一行实际能放下的像素宽度，把长字幕拆成连续的短条，时间轴按字数比例切开，编号重排，UTF-8 导出。转换前后对整份字幕做一次词元级校验——只要有一个字对不上就停手，不覆盖原结果。

两种模式 / two modes

v2.0 把原来两个独立程序（英文格式 v1.6、中文分词 v1.0）合进了一个界面。两种模式各走各的规则，互不串味。

模式一

英文 TK 格式

中文自动删除 · 适合发 TikTok / 海外版的英文轨

  • 每条最终字幕只大写第一个英文字母，其余全部小写
  • 按单词和像素宽度拆到下一条，不从单词中间断开
  • 检测到中文自动删除，并弹窗列出删掉了哪些片段
  • 纯数字对白正常保留，不会被误判成字幕序号
  • 英文、数字、标点、重音字母、表情全部参与防消失校验
模式二

中文智能分词

保留全部内容 · 适合国内平台的中英混排轨

  • 中文按实际像素宽度自动拆条
  • 中文、英文、数字、标点、表情一个不删
  • 英文单词和数字不从中间拆开
  • 逗号句号问号右括号等闭合标点不出现在下一条开头
  • 左括号、左引号、书名号尽量跟着后面的字走

两种模式都守的规矩 / common rules

导入不挑格式标准 SRT、无空行的紧凑 SRT、无序号 SRT，以及纯 TXT，都能读。
时间轴不跑偏保留原字幕整体起止时间，拆出来的新条按内容切分，不生成 0 毫秒字幕。
编号自动重排拆分后重新生成连续 SRT 序号，不用手动补。
防静默丢字转换前后做整份字幕完整性校验，校验不过就停手、不覆盖原结果。
导入即体检发现结束时间不晚于开始时间的坏条目会直接停止导入并报出来，而不是悄悄跳过。
导出即用UTF-8 编码 SRT，剪映直接识别，不用再转码。

三步走完 / how to use

双击 TK中英文字幕转换器_v2.0.exe，先选模式，再走三个按钮。

①
导入 SRT / TXT选中语音识别出来的原始字幕文件。
②
自动整理字幕先设好单行可用宽度、测量字体和字号，再点这个。
③
导出剪映 SRT检查右侧结果和状态栏的完整性提示，没问题就导出。

第 ② 步的单行可用宽度 / 字体 / 字号要和你在剪映里真正用的字幕样式对上——工具就是拿这三个参数去量像素宽度决定在哪断的。量错了不会报错，只会断得不像你想要的那样。

中途换模式是安全的。导入之后再切模式，程序会重新读取最初导入的那份字幕，并清空上一模式的处理结果——不会拿英文模式删过中文的结果再去跑中文分词，也不会重复转换。
