personalize 与 moodboard 的分工

首次成型:2026-05-01(02 教程账号级锚点章节) 升级:2026-05-01(《众声里的留白》创作时实测) 入档:2026-05-02 主线作品来源:02_角色一致性锚点/02_角色卡.md + 临时创作/2026-05-02/01_众声里的留白.md

一句话总结

personalize 是审美底盘,moodboard 是题材绑定——personalize 默认常驻,moodboard 按题材开关。

如何使用

你要做什么怎么开关
跑「檐下」相关人像personalize 开 + moodboard 开
跑非人像题材(抽象 / 风景 / 动物 / 概念)personalize 开 + moodboard 关
想看”完全没有我审美干预”的 base 输出personalize 关 + moodboard 关(对照实验用)

关键差异表

维度personalizemoodboard
性质静态、被动训练题材绑定的参考池
触发200+ 张图打分上传一组样片
作用范围跨题材(底盘审美)限题材(只对训练时的题材有效)
类比你的”审美 DNA”给 MJ 看一组”我喜欢这种样片”
跨版本兼容V7→V8.1 兼容 ✅V7→V8.1 兼容 ✅
遇到非题材怎么办仍生效(它是底盘)失效或反向干扰(它是题材绑定)

实测验证

验证 1 · 人像题材(《檐下》)

  • personalize 开 + moodboard 开 → 完美命中跳蛛先生的”清冷古风少女”审美
  • personalize 开 + moodboard 关 → 仍是中国脸,但缺少 moodboard 的”质感细节”
  • personalize 关 + moodboard 关 → 出”复古东方美人”(西方训练集偏差,见 AI甜妹脸vs复古东方美人_v1)

验证 2 · 非人像题材(《众声里的留白》抽象插画)

  • personalize 开 + moodboard 开(默认状态)→ moodboard 强行把”古风女性元素”塞进抽象画(灾难)
  • personalize 开 + moodboard 关 → 完美的抽象插画 + 仍带跳蛛先生的色彩偏好(底盘生效)

这次的发现极其关键:moodboard 是题材绑定的,它在非自己题材里反而是负担。

战略含义

1 · 写 prompt 前的开关 checklist

  • 题材是不是 moodboard 训练时的领域?(古风女性 / 古典摄影)
  • 是 → moodboard 开
  • 不是 → moodboard 关
  • personalize 默认始终开(它是底盘,跨题材都生效)

2 · 多 moodboard 战略(未来可能)

跳蛛先生现有 1 个 moodboard:“清冷古风”。 如果未来要做多种风格,可以训练多个 moodboard:

  • moodboard A:清冷古风(现有)
  • moodboard B:抽象概念插画
  • moodboard C:独立游戏视觉
  • …

每次跑图按题材选 moodboard,personalize 始终在底盘。

3 · 跨版本兼容是隐藏宝藏

很多创作者担心”升级 V8.1 会废掉我的训练”。 实测验证 personalize 和 moodboard 都跨 V7→V8.1 兼容—— 这是值得专门做一条作品的”安心剂”内容。

一个隐藏的内容点

“moodboard 是题材绑定的,personalize 是底盘审美。”

这句话听起来是技巧贴,但展开说是一个 IP 战略层面的洞察:

  • moodboard 锁审美质感(图像层)
  • personalize 锁审美方向(认知层)

跳蛛先生的”清冷古风”是 moodboard 的显性表达; 他的”实证理性 / 反水文 / 文学气” 是 personalize 训练里隐性沉淀的审美方向。

两者叠加 = 一个有”性格”的账号,而不是”用了同款工具的账号”。

顶层金句段

“moodboard 是题材绑定的,personalize 是审美底盘。 跑非人像题材(抽象/插画/概念图)时关掉 moodboard, 但 personalize 默认开,因为它是你 200 张图打分训出来的整体审美, 不只对人像生效——它在抽象题材里同样在悄悄’调味’。”

“personalize 锁审美方向,moodboard 锁审美质感。 缺前者,你只是用了同款工具。 缺后者,你的图缺了一层无法言说的细腻。 两者叠加,你的账号才有’性格’。“

升级补丁(2026-05-02 自由探索副会话二 · 胶片人像探索)

来源:在跑”清冷东方少女回眸”系列时,加入”清冷古风”moodboard 让产出有质的飞跃 —— 把 prompt v5(西式胶片人像题材)从”OK”推到了”惊艳”。 实测样本:临时创作/2026-05-03_multi_sref探索/胶片人像探索/ 的 5 张”清冷少女回眸”

修正一:Moodboard 的贡献维度比”肌理”更广

之前理解 moodboard 是”题材绑定的肌理参考池”。这次发现它还会贡献:

  • 情绪 register(清冷气质 vs 暖光私密)
  • 姿态 archetype(把 prompt 模糊句 head turned toward window light 解读成”回眸看观者”)
  • 色调倾向(冷调微调)

修正性质:Moodboard 不只是”肌理参考池”,更准确的说法是 —— 它在 prompt 没强力指定的所有维度上,自动调味。

修正二:“自家题材边界”按主体定义,不按场景题材定义

之前那条”moodboard 在非自家题材里反向干扰”判断,基于 众声里的留白 抽象插画 —— 那是主体不匹配 + 题材不匹配。

这次场景是 主体匹配(清冷东方少女)+ 题材不匹配(西式胶片人像) —— moodboard 没干扰,反而精准贡献了主体维度。

更准确的规则:

Moodboard 的”自家题材”边界主要按主体定义。 主体匹配 → 不冲突的所有 prompt 模糊处都是加成 主体不匹配 → 强行套主体导致干扰

修正三:Moodboard vs Prompt 的”影响力分配”机制

新增一条心智模型:

Prompt 强约束的维度(环境、构图、服装色、时间) → moodboard 影响小 Prompt 模糊或未指定的维度(气质、姿态、面孔细节、色调) → moodboard 强势介入

实操含义:你想 moodboard 贡献什么,就在 prompt 里”留白”什么 —— 别把所有维度都写满。这次 prompt 故意保留 head turned slowly toward the window light 这种带歧义的描述,给了 moodboard 把它解释成”回眸”的空间 —— 这是这次出爆款的隐藏机制。

修正后的”何时该开 moodboard”判断

旧的 checklist:

  • 题材是不是 moodboard 训练时的领域?

修正版 checklist:

  • 主体是不是 moodboard 训练时的目标?(不是题材!)
  • Prompt 是不是给 moodboard 留出了”留白维度”让它发挥?

两个都是 yes → 开;任一是 no → 关。

升级补丁(2026-05-03 · V4 基准图修复 R2 双盲对照实验)

来源:V4 基准图修复训练场 R2,因误操作产生的天然双盲对照(同 prompt × personalize 开/关) 实测样本:09_V4基准图修复训练场/04_产出_待跑/R2_chin-lowered-eyes-meeting-lens_带personalize/ 8 张 vs R2_chin-lowered-eyes-meeting-lens_没带personalize/ 8 张 入档当日:跳蛛先生跑 R2 时不慎只开 moodboard 没开 personalize,补跑了一组带 personalize 的——意外得到天然 A/B 对照样本

修正四:personalize 是”审美方向锚”——从理论命题升级为实证事实

之前在文档里说”personalize = 审美底盘 / 审美方向”——这是结构推理,不是实证。

R2 的对照实验首次给出硬证据:

  • 同一个 prompt(chin slightly lowered, eyes meeting the lens through falling snow, wet eyelashes + 完整 V4 prompt 主体)
  • 同一个 moodboard(“清冷古风” 全程开)
  • 唯一变量:personalize 开 vs 关
  • 各跑 8 张

结果:

  • 几何拓扑两组一致——“头微低 + 看镜头 + 湿润”在两组都被成功触发,prompt 几何描述跨 personalize 状态稳定
  • 气质天差地别:
    • personalize 开 → 8/8 保持”清冷少女”:唇色自然、瞳色正常、表情含蓄、年龄感少女
    • personalize 关 → 8/8 退化为”复古东方美人”陷阱:深酒红唇、红/茶色瞳、妩媚成熟、年龄感拉到 25-30

含义:三个锚的分工进一步清晰

锚管什么不管什么
prompt几何 / 环境 / 构图 / 服饰气质方向 / 质感
moodboard质感 / 肌理 / 留白维度的调味(只在共识维度有效)几何 / 气质方向
personalize气质方向:唇色取向 / 瞳色取向 / 表情底色 / 年龄感几何 / 质感

三者互不替代——这是 R2 对照实验最干净的产出。

这条与 AI甜妹脸vs复古东方美人_v1 的关系

R2 的”不开 personalize 组”完美复刻了那篇文档里描述的”复古东方美人”陷阱——同样的深酒红唇、同样的红茶色瞳、同样的妩媚成熟感。

这是同一陷阱的双盲实验版本——比那篇文档的”裸跑就出复古东方美人”多了”开 moodboard 也救不回来”这个增量证据:moodboard 救不了 personalize 的缺位(因为它们管的是不同维度)。

实操升级:checklist 升级为”强制三开”

之前 checklist 里 personalize 写”默认开”——现在升级为强制开,任何”清冷少女”题材都不可关:

  • personalize 强制开(关 = 必出复古东方美人,moodboard 救不回)
  • moodboard 按主体边界开关(主体匹配且想留白调味 → 开;主体不匹配 → 关)
  • prompt 几何写实 + 气质留白(气质交给 personalize,质感交给 moodboard)

升级补丁(2026-08-05 · 三角色定妆 · 性别覆盖假说)⚠️

来源:2026-08-05_三角色校园人像定妆_MJ复盘_v1(同一天、同一 profile、三个角色:两女一男)

修正五:personalize 的”底盘”可能不是均匀的

本档一直把 personalize 描述成跨题材生效的审美底盘。三角色定妆那次给出了第一个反例观察——底盘可能有厚有薄:

  • 女性侧两个角色 → 没掉进复古东方美人陷阱,修正四的结论完全成立
  • 男性侧一个角色 → profile 开着,V1 仍出韩系男团脸,没被拽回作者的审美方向
  • 旁证:三个角色的唇都偏红润带光泽——签名确实跨性别生效了,但在女性侧是加分、在男性侧是减分(把”薄唇寡言”的设定撑成了偶像唇)

假说:personalize 的 200+ 张打分训练集若性别分布倾斜,弱覆盖的那一侧只剩下一层很薄的偏好,不足以对抗 base model 的默认原型——但作者会误以为”profile 开着 = 审美方向已受控”。

⚠️ 未验证:那次没跑关 profile 的对照 A/B。验证方法沿用修正四的做法——同一条男性 prompt,带 / 不带 profile 各跑 8 张背靠背。

在验证之前的操作口径:把 checklist 的”personalize 强制开”理解成必要条件而非充分条件——弱覆盖题材(本次是男性人像)仍要在 prompt 正文和 --no 里正面压制,不能指望底盘代劳。

升级补丁(2026-08-24 · 二十八宿星官)⚠️ 含当日自我更正

来源:2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘_v1 ⚠️ 本补丁的初版被当晚推翻。初版依据一批”加 personalize + moodboard 后题材整个被替换”的出图,写了修正六「跨族时 moodboard 会覆写明确指令」与一张失守表。核对作者实际 prompt 后发现那批跑的不是星官 prompt,逐项对照零失守,该表全部作废。作废经过与逐项核对见 moodboard主体位判据_假说_v1。

修正六:修正二的「主体匹配」判据可能太粗(🔬 待验证)

修正二把边界定为「主体匹配 → 加成」,判据是”主体是不是 moodboard 训练时的目标”。

待验证的细化建议:当 moodboard 主体是”当代东亚年轻女性”、prompt 主体是”古典东亚年轻女性(星官神仙)“时,按性别 / 年龄 / 族裔看完全匹配,照修正二应判”开”——但这两者的年代、身份、画种都不同。

提议把「同族」判据升级为三项全同:

维度例
年代当代 / 古典
身份写真模特 / 神话人物
画种摄影 / 工笔插画

🔬 未验证:这条细化目前没有任何实测支撑,是从修正三的机制外推的。验证方法见 moodboard主体位判据_假说_v1。在验证之前,修正二与修正三维持原状,不要按本条改工作流。

同族侧的一个正面样本(2026-08-24)✅

同一轮里有一条干净的人物题 ＋ 同族样本:当代清冷少女 prompt × 当代美女写真 moodboard × personalize 开 × 无 sref,全项命中,脸质量明显优于此前挂无脸 sref 的几批。

这印证修正二(同族 → 精准贡献主体维度),同时印证 参考图缺失维度不可继承律_v1 的操作建议——脸不走 sref,走描述锚定 ＋ personalize;撤掉 sref 反而把脸修好了。

修正七:personalize 在古典 / 神话题材下可能是负债(🔬 待验证)

修正四把 checklist 升级成”personalize 强制开”,其场景是当代清冷少女——personalize 的作用正是把脸从「复古东方美人」拉回当代。

推论:当题材要的就是复古原型时(古典星官神仙:丹凤眼、垂眸、橙红唇、古典气度),这个作用方向是反的,开 personalize 反而会把脸拉当代、破坏古典味。

已有的半边证据:同批一张裸跑(无 personalize、无 moodboard)的星官图,一版即得标准复古东方美人。这说明关掉就能拿到,✅ 成立。

当日晚间补上了受控样本(合挂形态)⭐:昴日鸡 prompt 逐字相同、seed 42/43 配对,唯一变量 --profile qwksp9b dsdxtdr(qwksp9b = personalize、dsdxtdr = 美女写真 moodboard,合挂)。结果:挂了的 7/7 画种从中式插画翻转成写实摄影,脸从古典画中人变当代真人,红色像素约 7 倍(红鸡冠 / 正红唇出现);黑底 / 神鸡 / 汉服 / 构图守住。详见 2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘_v1。

决策层已定案:古典插画题材,这条尾巴不能挂。🔬 归因层仍未隔离:合挂测不出”脸的切换”归 personalize 还是随画种翻转自然发生。隔离方法:--profile qwksp9b 与 --profile dsdxtdr 各单挂一个 job,与本轮四方对比。

操作口径(升级):古典 / 神话 / 年代题材,先按 默认落点的资产负债判断_v1 问一句「我要的脸是不是 base model 的默认落点」——是,就裸跑,整条尾巴都别挂(A/B 已证:裸跑即得正确形态,挂尾巴画种直接翻转)。详见 AI甜妹脸vs复古东方美人_v1。

跨族方向反转观察(2026-08-24 · 解释框架,未隔离)🔬

A/B 的结果与本档的分工表严丝合缝,只是方向反了:personalize 管脸——B 组脸变当代;moodboard 管质感媒介——dsdxtdr 是写真板,B 组画种变摄影;红色渗入落在两者交界。

同一套分工,在同族题材上是”各管各的帮你”,在跨族题材上是”各管各的拖走”——每个工具都往自己训练集的方向拖,拖的正好是自己管的那条赛道。

这句话若被单挂实验证实,就是本档分工表的负向对偶,值得升格独立成档。目前只是”解释得通”。
