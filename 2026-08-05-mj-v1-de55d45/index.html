2026-08-05 · 三角色校园人像定妆 MJ 复盘

入档:2026-08-05 性质:合作委托的角色定妆 prompt 迭代复盘,非比赛,无票数 / 无平台数据 关键词:林晚 / 校草 / 闺蜜 · 五官堆叠词块 · 年龄轴 vs 颜系轴 · personalize 性别覆盖

事实记录（不可修改区）

  • 作品名称:三角色校园人像定妆(女主「林晚」/ 男主「校草」/ 女配「闺蜜」)
  • 项目:合作者(同事)提供角色卡,本人负责翻译成 MJ prompt 并跑图定版。非比赛
  • 时间:2026-08-05 21:31 – 22:14(下载时间戳区间)
  • 工具:Midjourney --v 8.2 --style raw,personalize(—profile)全程开启
  • 最终结果:三个角色全部定版,创作者与合作者共同确认(原话「这几版我和我的朋友(同事)都很喜欢」)
  • 出图量:男主明显多于其他两个角色;女主与闺蜜各一批即过。具体张数未计数(Downloads 里只有下载的 9 张,≠ 出图数)
  • 迭代轮次:女主 1 版 prompt · 闺蜜 1 版 prompt · 男主 3 版 prompt
  • 数据来源:创作者对话内反馈 + 本地下载图时间戳。无平台数据、无第三方评价
  • 未验证项:188cm 身高从未验证(全程只跑近景,全身版一次没跑);建议的「关 profile A/B」未执行

作品回顾

三个角色卡都由合作者用中文口语写成,含五官、气质、穿搭。我的工作是翻译成 MJ prompt。

执行路径:

角色词块来源prompt 轮次结果
女主 林晚(软萌腼腆)清冷少女五官堆叠基础句_v1 换气质层(cold reserved aloof → gentle warm approachable)1一批即过
男主 校草(清俊寡言 · 188)无模板,从零现编3V1 被误判 → V2 方向错误 → V3 定版
女配 闺蜜(路人级 · 只要求”气质跟女主不一样”)从已过关的女主逐层反向翻转1一批即过

结果分析

命中率不对称的根因不是运气，是有没有可迁移词块

女主和闺蜜各一批过,男主跑了三版 prompt 加多批图。三个角色是同一天、同一个人、同一套参数、同一个 personalize——唯一的结构性差异是有没有现成的词块可迁移。

  • 女主:库里有 清冷少女五官堆叠基础句_v1,换一层气质词就位
  • 闺蜜:有已过关的女主当参照,逐层取反即可
  • 男主:库里只有女性侧两个词块(东方美人 / 清冷少女),男性侧是空的,只能现编

这次的最大产出因此不是三张图,是 男性五官堆叠基础句_v1 这个补上的库缺口。

男主三轮的真实过程（含我的判断错误）

轮次我的判断实际
V1我判为**“韩系偶像脸漂移,方向反了”**,列了 4 条问题❌ 判错了。“韩系”是风格归属判断,不是客观缺陷。客观缺陷只有两条:年龄看着 17–18(设定 21)、窄肩细脖(设定 188 修长)
V2合作者补了对标”许凯 / 嘉尔”,我据此改成浓颜骨相堆满版,并把 --stylize 从 100 提到 200❌ 实际跑图,创作者确认不理想。浓颜堆过头 = 猛 / 凶,不是帅
V3创作者反推:“第一版那个韩版更贴合校草”。我据此回到 V1,只加年龄锚与体格锚,五官一个字不动✅ 一批即过,定版

两个必须写下来的教训:

  1. 判错的方向:我把”这张脸属于哪个审美体系”当成了”这张脸有没有做到角色卡”。前者是归属,后者才是缺陷。归属判断不构成返工理由。
  2. 对标 ≠ 设定:合作者同时给了「校草」(角色设定)和「许凯 / 嘉尔」(明星对标),这两个词指向不同原型——校草是淡颜、清爽、够得着;许凯 / 嘉尔是浓颜、有距离感的银幕原型。我当时指出了这个冲突,但默认对标优先,选错了边。正确的默认是信设定标签——那是创作者自己写下的、描述角色在故事里的功能;明星对标往往是被追问时临时给的类比,只对应”帅”这个模糊感受,不对应具体的脸。

personalize 全程开着，但两性表现不同

这是本次最值得继续观察的一条:

  • 女性侧工作正常:女主和闺蜜都没掉进 AI甜妹脸vs复古东方美人_v1 描述的复古东方美人陷阱(深酒红唇 / 红茶瞳 / 25–30 妩媚),出的是当代中国审美。印证旧铁律
  • 男性侧没能阻止韩系倾向:V1 是在 profile 生效的情况下出的韩系男团脸
  • 旁证:三个角色的唇都偏红润带光泽——这更像同一个 personalize 签名跨性别生效,但它在女性侧是资产、在男性侧是负债(把”薄唇寡言”撑成了偶像唇)

假说:personalize 的训练集可能存在性别覆盖不均——女性图多、男性图少,男性侧就退回 base model 或被弱偏好带偏。⚠️ 本次没有跑关 profile 的对照 A/B,这条只能挂”待验证”,不能当结论用。

装扮签名律的新应用面

装扮签名vs五官精度_v1 原本讲的是同一角色跨图一致性(装扮 4/4、五官 0/4)。这次把它用在了两个角色的一次性区分上:

闺蜜是路人级角色、镜头少、没时间靠出场次数建立辨识度,所以给了两个一眼可辨的签名——高马尾(对撞女主的空气刘海)+ 焦糖色外套(对撞女主的奶白冷色系),再叠一个露齿大笑(对撞女主的抿嘴浅笑)。一批即过。

同一条律,新应用面:装扮签名不只解决”是不是同一个人”,也解决”是不是不同的人”。

反向翻转表（闺蜜的实际做法，可复用）

层女主(已过关)闺蜜(取反)
脸型圆润鹅蛋略带棱角、下巴清晰
眼尾下垂(无辜)上挑(有神)
眉淡自然平眉较浓直眉
笑抿嘴浅笑 + 梨涡露齿大笑 ← 最快的气质对撞
发型中短发 + 空气刘海(遮额)高马尾 + 露额
色系奶白 / 浅粉 / 浅灰(冷调浅色)焦糖 / 砖红(暖色)
环境色温冷灰保持冷灰,只在人身上给暖色

最后一行是刻意的:环境统一 + 主体撞色,两张图既能拼在一起,又一眼分得开。

遗留问题（不是赢点，但必须记）

  1. 创作者最喜欢的男主那张,恰恰是最不符合角色卡的那张——它敞怀、内搭黑色打底衫没出现,而角色卡明确写了内搭。同批另一张打底衫在、更符合卡。“创作者选中的”和”最符合角色卡的”不是同一张,定版时要分清是在定”脸的锚”还是”成片镜头”
  2. 闺蜜定版露肩——prompt 里从没写过露肩,是 MJ 的自动时尚化处理。跟”校园闺蜜”的设定不搭,也逼近审核边缘
  3. 三个角色色温不统一:男主定版偏暖朦胧、女主偏冷灰、闺蜜居中。同框时会像三部片子。建议过的”用女主那张当 sref 统一质感”没有执行
  4. 188cm 全程没验证——三个角色都只跑了近景,身高只有全身版才验得了。锁身高的三重锁定写法写了但一次没跑过
  5. 关 profile 的归因 A/B 没跑,所以 personalize 性别覆盖那条只能是假说

方法论沉淀

1 · 「不够帅 / 不够美」是年龄轴，不是颜系轴

核心:审美类反馈先分轴(年龄 / 颜系 / 骨架 / 光影),默认先试年龄轴——它是单调的;颜系轴是倒 U 型,堆过头就从帅变凶。

来源:男主 V1→V2→V3,V2 浓颜版实际跑图确认不理想,V3 只改年龄和体格就过。

验证状态:⚠️ 首次发现(含实测证伪)——单角色单项目,但反向版本真的跑了,不是纸面推断。

已抽成原子单档:不够帅是年龄轴不是颜系轴_v1

2 · 身份标签词优先于外部明星对标

核心:角色设定里的身份标签词(校草 / 学霸 / 邻家妹妹 / 大小姐)本身就是一个审美原型包,它比创作者临时给的明星对标更接近真实意图。两者冲突时默认信标签。

来源:合作者同时给「校草」和「许凯 / 嘉尔」,我默认对标优先,选错;创作者反推后按标签走,一次过。

理由:标签是创作者主动写下的、描述角色在故事里的功能;明星对标常是被追问时临时给的类比,往往只对应”帅 / 好看”这个模糊感受,不对应具体的脸。

操作规则:

  1. 两者冲突时先把冲突点讲出来,明确问创作者哪个优先,不要自己默认
  2. 拿不准时默认信标签
  3. 明星对标先过 指定对象与气质描述_生成路径分岔律_v1 的判据:观众要不要认出来——要,就不是气质描述,文字堆不出来

验证状态:⚠️ 首次发现(单项目)

反例 / 边界:如果标签本身很空(如”男主角""路人”),那它不携带原型,该信对标。

3 · personalize 可能存在性别覆盖不均

核心:personalize 修正的是”训练集里你喂过的那类脸”。若训练集性别分布倾斜,弱覆盖的那一侧会退回 base model 或被弱偏好带偏,而作者会误以为”profile 开着就都受保护”。

来源:同一天同一个 profile,女性侧两个角色都避开了复古东方美人陷阱,男性侧第一版出韩系男团脸;三个角色的唇都带同一种红润光泽(签名跨性别生效,但只在一侧是资产)。

验证状态:⚠️ 假说,未验证——没跑关 profile 的对照 A/B,不能当结论用。

下次验证方法:同一条男性 prompt,带 profile / 关 profile 各跑 4 张背靠背,排除时机干扰。

已回填:AI甜妹脸vs复古东方美人_v1 · personalize与moodboard分工_v1

4 · 装扮签名律的新应用面：一次性区分两个角色

核心:装扮签名不只解决”是不是同一个人”,也解决”是不是不同的人”。镜头越少的角色越依赖它——没有出场次数可以建立辨识度,只能靠一眼可辨的两三件物件。

来源:闺蜜(路人级)靠”高马尾 + 焦糖外套 + 露齿笑”三件,一批即过。

验证状态:⭐⭐ 原律已多次验证,本应用面首次。

操作规则:给配角设计签名时,每一件都要与主角形成对撞(发型对撞、色系对撞、表情对撞),而不是各自独立好看。

已回填:装扮签名vs五官精度_v1

5 · 有可迁移词块的角色一批过，零模板的反复重跑

核心:同一天、同一人、同一参数下,角色的命中率差异主要来自有没有可迁移的五官词块,不是题材难度。

来源:女主(换轨现成词块)1 版过、闺蜜(反转已过关角色)1 版过、男主(零模板现编)3 版。

验证状态:⚠️ 首次发现(单项目,n=3)

操作规则:接到新角色卡先查库里有没有同性别 / 同气质的词块;没有就先花一轮把词块本身写出来,别边跑边编。

下次改进

  1. 接角色卡先查词块,没有就先建。本次已补 男性五官堆叠基础句_v1
  2. 审美反馈先分轴再改 prompt,“不够帅”不是可执行指令
  3. 设定标签与外部对标冲突时,当场问创作者哪个优先——这次是我自己默认,选错了边
  4. 定版后立刻跑 sref 统一色温,别留到同框才发现三个角色不在一个体系里
  5. 近景定完脸就跑一次全身版,否则身高 / 下装 / 鞋这些属性一次都没被验证过
  6. 区分”定脸的锚”和”成片镜头”——最好看的那张不一定是最符合角色卡的那张
