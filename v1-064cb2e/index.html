即梦锋芒回响:画布绑定发布与开源画布整理

入档:2026-10-14 来源:84_那道题还亮着 MV 报锋芒回响(9 月 20 日版)。10-13 先在即梦探索页发了短片,10-14 读《即梦优质画布激励细则》才发现画布要从画布入口绑定发布,于是整理画布、重发一条画布绑定版,当天提报 验证状态:⚠️ 首次;画布和绑定短片提交时都还在审核,「优质」档能不能评上未知

一句话

锋芒回响的画布激励,短片必须从画布入口「发布 → 上传新短片」发,不能先在探索页发、再回头绑定。所以顺序是:先把画布整理好,再从画布发短片,最后提报。顺序反了,只能再发一条重复的短片,旧的那条隐藏掉。

如何使用

发布顺序

  1. 成片定稿后先整理画布(下一节),再发短片。
  2. 即梦网页端:资产 → 画布 → 目标画布卡片右下角「···」→ 发布 →「上传新短片」。弹窗里要填视频(作者手传)、封面、标题(≤40 字)、分类(最多 2 个)、简介、允许下载。弹窗也有「关联已有短片」选项,但细则明确要求选「上传新短片」。
  3. 一个画布只能绑一条短片。发出后短片和画布模板分开审核,一般 1–3 个工作日。
  4. 抖音同步发布,带话题 #即梦AI创作者成长计划,视频和描述里不能有其他 AI 工具名(做一版「无竞品版」,片尾署名把具体工具写成 AI)。
  5. 提报表(飞书多维表格表单):第 15 题「是否已发布画布」选「是」后,才会冒出第 16 题「奖励档位」,最多选 2 项,保底的 2000 积分必勾。细则写的是每件作品只报一次、运营按达到的最高档结算,所以不必为了等数据拖到截止日。

「优质」画布的验收项(细则原文的要点)

  • 四个核心阶段都留痕:概念设计、分镜、视频生成、时间线粗剪。
  • 至少 4 个有效概念设计,覆盖角色、场景、道具、风格里的至少 2 类。
  • 至少 10 个能对应到分镜的视频结果;至少 1 个时间线粗剪节点,能对应到最终镜头顺序。
  • AI 直接生成的时长占成片 ≥80%。
  • 节点参数完整,要用到主体容器。
  • 素材按阶段打组、组有标题,进入成片的节点能沿连线追溯到上游输入。
  • 画布激励只在短片达到 10 万播放档以后叠加(200 元起)。画布开源后,别人能看到全部提示词、参考图和连线,还能复制模板。

事后整理一个只有生成节点的画布(不花积分)

84 的画布原来只有 28 个生成节点:参考图、白模预演、首帧截图都是在提示词里按资源 ID 引用的({{res:…}}),画布上看不出来源。整理脚本见作品仓库 84_那道题还亮着_MV/_脚本/画布整理.py:

  1. 把每个被引用的资源建成节点:node create image|video --resource-id <已登记资源> --import-kind local_upload。
  2. 把生成节点提示词和 --ref 里的 {{res:X}} 换成 {{node:Y}},用 node edit 写回,不加 --run。实测产物、状态都不变,连线立刻出现。改之前先拿一个节点试,改完逐个核对资源列表没变。
  3. 用 node create element 建主体容器,node create text 写分镜表(可以从每段提示词里抽「镜N(起–止秒)」换算成原曲时间),node create timeline --clip <节点>,trim=<起点ms>-<长度ms>,speed=… 按剪辑 EDL 拼粗剪,配上传的原曲。
  4. CLI 能读位置、不能写位置,也不能打组。打组只能在网页上做(下一节)。

网页打组(画布是 React Flow)

  • **别单击节点。**单击生成节点会弹出生成面板(上面就是提交按钮);图片节点上方的工具栏点一下,就会新建一个「人物三视图」之类的空节点。
  • Shift / Ctrl 加点选做多选无效:这个画布的多选看的是键盘按下事件,不是点击事件带的修饰键。
  • 可行的做法:
    1. 用 JS 在节点元素上合成 pointer / mouse 拖拽,把各阶段的节点排进各自一块空地。拖拽开头先沿方向多走 13 像素,补上拖拽阈值吃掉的那段;目标位置上有别的节点会被避让推开,所以要选空地;指针拖出可视区会触发自动平移,每次只拖一小段,多拖几次逼近。
    2. 用真鼠标从空白处框选一整块,按 Ctrl+G 编组。
    3. 选中组 → 缩放菜单「缩放至选中项」→ 双击组标题,改名。
  • 窗口在后台时,setTimeout 和渲染都会被限速。用 MessageChannel 让出线程,读坐标前先截一次图,促使页面重新渲染。

二次实做（88 号《第三阶的秋天》，2026-10-22）

  • 这次顺序是对的：先用 _脚本/画布整理88.py 整理画布（19 个输入节点、res→node、主体「她」、分镜表、时间线），再从画布「上传新短片」发，一次成。
  • 打组换了更简单的做法：用 playwright 的真实鼠标（mousemove / mousedown / mouseup）拖节点，按住 Shift 从空白处拖框框选，Ctrl+G 成组，双击 span[data-node-title-full-text] 改组名。上文「Shift 加点选无效」只说点选，Shift 拖框是有效的。单独一个节点（时间线）不能成组。
  • 提报表单：文本题是 contenteditable，要 scrollIntoView 后真实鼠标点再输入；时间、数字是 input，Ctrl+A 清空再输入、回车；第 11 题「提报时间」默认填的是打开表单的时间，要改成实际提交时间。即梦作品 ID 从个人页「AI短片」tab 点进作品读 URL；抖音作品 ID 要在自动化浏览器里登录 creator.douyin.com，从作品管理页点进作品读 URL。截图用作品管理页搜片名的结果，数字和第 13 题一致。
  • 作者这次没有当天交，决定等 72 小时用新数据再交。上文说按最高档结算、不必等数据，这条仍然成立；等不等是作者的选择。

边界

  • 只做过一次。「优质」档最终能不能评上,要等审核结果。
  • 84 的视频生成是直接引用定妆照做的,主体容器「她」是事后补的,没有真正参与生成。要满足「用到主体容器」,下一部片子要从一开始就用主体去生成;为了达标去改生成记录等于伪造创作过程,这次没有改。
  • 画布开源后,参考图本身也会公开(84 的参考图出自其他工具,画布里没有写出处)。
