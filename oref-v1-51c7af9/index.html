oref 高方差律 — oref 不是不能用,是方差大

首次沉淀:2026-06-17(项目 47 霜见 · 斗笠女侠写真) 验证状态:⭐ 首次发现 / 强疑似——细化 2026-06-11_晴枝发布复盘_oref污染与工具回归_v1 的「oref 污染美学律」 适用:MJ v8.1 角色一致性 / 写真类项目

一句话总结

MJ 的 oref 锁脸不是不能用,是高方差:同一套 prompt 反复跑,有的塑料浓妆/五官异常,有的皮肤自然骨相端正。问题在方差,不在上限。 抽卡足够多 + 逐张过验收,能稳定捞到好图。

与「oref 污染美学律」的关系

2026-06-11_晴枝发布复盘_oref污染与工具回归_v1 提出:oref 倾向引入磨皮浓妆塑料感,美学优先项目慎用。该结论基于晴枝单项目、连续翻车的样本。

本律是它的细化:污染是概率倾向,不是必然。

  • 晴枝当时刷到的几张恰好落在”塑料”那一侧 → 得出”慎用”。
  • 项目 47 继续抽卡,捞到明显合格的自然皮肤好图(R3 keeper) → 证明好图存在,只是命中率低。

两条不矛盾:慎用 = 别指望一两张就成;高方差 = 多抽必有好的。

实证(项目 47)

  • 前期 oref 刷三组,塑料/异常为主,一度判定弃用。
  • 同体系继续抽卡,捞到 keeper_01:皮肤自然无磨皮、冷艳骨相与定妆图一致、装扮签名齐、无手部/五官异常,过验收。

操作规则

  1. 要用 oref → 当它是抽卡游戏:一次至少 8-12 张,默认大半要丢。
  2. 逐张过验收:① 素颜毛孔(无磨皮塑料);② 无五官/手部异常;③ 骨相气质对。只留三项全过的。
  3. 描述锚定永远是底座:sref(风格)+ 五官骨相词块 + 装扮签名,无论开不开 oref 都带。开 oref 时它减少飘移,不开时它独立成团(见 装扮签名vs五官精度_v1)。
  4. 方差太痛 → 退一步用 moodboard:攒 3-5 张过验收的脸做 moodboard 软锁,稳定度介于”纯描述”与”oref”之间,且不带 oref 的塑料倾向(晴枝实测发布四图即此路径)。

路径选择速查

需求路径
美学优先、要稳、怕塑料oref-off:描述锚定 + sref
更接近同脸、愿意抽卡oref-on + 抽卡验收
多图系列要又稳又像moodboard 软锁
