moodboard 跨题材审美迁移（人物 moodboard 当通用审美增强器）

入档：2026-06-26 来源：2026-06-26 morning PB R1「真空包装天空」意外发现（2026-06-26_morningPB双轮_空与黄昏晒屁股复盘_v1） 验证状态：⭐⭐ 跨题材二次验证通过（2026-06-26 真空包装天空静物 + 2026-06-29 弄巧绒花静物，两个独立题材均见 moodboard 审美增益）。详见下方「二次验证」。

一句话

一个为某题材（如美女写真）长期调校的高质量 moodboard，承载的不是内容（美女），而是创作者的审美风格基底（光影 / 质感 / halftone 复古调 / 精致度）。把它跨题材迁移到静物 / 场景 prompt 上，能整体抬高出图的审美天花板。

发现经过（干净 A/B）

R1 出「真空包装天空」时，意外忘记关闭专做「中国美女写真」的 moodboard：

  • 开 moodboard（意外）：出图惊艳——halftone 复古、质感精致、构图考究（即当日 R1 定稿那张）。
  • 关 moodboard，同一条 prompt 重生成：质感松散、画面粗糙，明显掉档。

唯一变量是 moodboard 开/关，prompt 一字未动 → moodboard 是那份美学的来源，不是 prompt 的功劳。（此发现同时修正了 R1 复盘的归因：R1 美学≠prompt 设计，是 moodboard 加成。）

机制：moodboard 迁移的是「审美基底」，不是「题材内容」

人物写真 moodboard 里反复出现的，除了「人」，还有创作者长期筛选沉淀的光影偏好、材质偏好、色彩调性、精致度阈值。这些是题材无关的审美基底，迁移到任何主体上都能抬升质感。这与 personalize与moodboard分工_v1 互补——personalize 学的是账号长期审美，moodboard 是可即时挂载的审美包。

⚠️ 配套边界：内容泄漏 → NSFW ban

moodboard 会把内容倾向（人体 / 裸露质感）也泄漏进主体，不只是风格：

  • R2「黄昏晒屁股·雕塑」挂同一 moodboard → MJ 审核直接 ban，大概率把真人裸臀质感渗进了雕塑，触发 NSFW。

操作边界：

题材能否挂人物 moodboard
✅ 无人体的静物 / 场景 / 物件题可，大胆借审美
⛔ 人体 / 敏感 / 可能被联想成裸露的题（屁股、人体雕塑、贴身）关掉，否则 ban

与 moodboard拉力陷阱_v1 同脉——moodboard 的「拉力」既能抬审美，也会把内容倾向拽进来，是双刃。

💡 资产建设建议：养第二个「纯质感 moodboard」

由这次教训直接长出的最佳实践：

  • 单独养一个 纯质感 moodboard——只收无人物的高质量图（halftone 复古、光影、材质、色彩调性）。
  • 专用于跨题材审美增强，彻底规避内容泄漏 ban，任何题材（含人体题）都能挂、不翻车。
  • 按题材开关：静物题挂人物 board 也行；人体/敏感题只挂纯质感 board。

二次验证（2026-06-29 · 弄巧绒花静物）

跨到全新题材非遗绒花静物（七夕短片「弄巧」的 sref 锚出图）再验一次，结论一致，并补一刀精度：

  • 叠加方式：personalize（开）＋ 专做「美女写真」的 moodboard（叠挂）。
  • 对照：仅 personalize vs personalize＋moodboard → 后者美学质感明显更高（光影 / 质感 / 高级度）。
  • 新精度：moodboard 的增益是叠在 personalize 之上的增量，不是二选一——印证 personalize与moodboard分工_v1（personalize＝账号长期审美底子，moodboard＝可即时叠挂的审美包，二者叠加 > 单用 personalize）。
  • 边界复核：本题为无人体静物（绒花），挂人物 moodboard 未触发 NSFW，与上方边界表 ✅ 一栏一致。

来源：2026-08-24_二十八宿星官_黑底探索与一次结论作废复盘_v1。

本档的 ⭐⭐ 二次验证有一个此前未被点明的共同前提：两个样本（真空包装天空、弄巧绒花）都是静物题，画面里没有人。

这是可核对的事实，不依赖新实验。它说明本档「moodboard 迁移的是审美基底不是题材内容」这个结论，目前只在无人画面上被验证过——人物题上是否同样成立，本档没有样本。

可能的机制（🔬 未验证）：静物画面里没有位置能安放 moodboard 的人物内容，人物信号无处落地，只剩风格基底渗过来。一旦目标题材也是人物，那个位置就出现了。归类框架见 moodboard主体位判据_假说_v1。
