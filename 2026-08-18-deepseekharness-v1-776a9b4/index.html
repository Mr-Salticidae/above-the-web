DeepSeek Harness 保姆级教程 · 两日全链路协作复盘

日期：2026-08-18 · 项目：钉钉文档《DeepSeek Harness全案实测，保姆级教程》 协作方：Genji 团队（口播手稿+录屏素材）、跳蛛先生（决策+分段+结构）、桓（口播补写+实操验证+钉钉落库） 状态：理论部分全部完成，实战案例部分启动（学员共创）

一句话律

先实操后写稿——演示类口播必须先在真机跑通再落笔，凭想象写必然返工。

项目时间线

08-17：5 章节口播补写（安装/界面/定位/成本/能力对比）→ 6 个专业名词批注框 → Harness E盘部署（3 坑：koffi 原生模块 / NODE_OPTIONS 钩子 / 旧 profiles 软链）→ Claude 桌面修复 → 5 张配图上传 → Cowork 指令/回执闭环跑通

08-18：回执验收 + 04/05 重截版上传（7 张配图全部就位）→ 4 个能力实验实操验证 → 能力 1-6 口播对标重写（含斜杠命令新增章节）→ 权限/边界板块按对标修正（Preset 与权限边界两维度解耦）→ 提示词框架 4 段 → 交接文档（配图与录屏导演手册）→ 本复盘

核心方法论

1. 先实操后写稿（用户否决凭想象写）

最初按概念解释写能力章节（每段 100-150 字），被否：“太简单了，去看对标”。对标《90min Codex小白系列教程》的标准是每能力 300-500 字实操演示叙事（提示词原句 + 操作路径 + 实测结果 + 段尾钩子）。且用户进一步要求：先在 dsh 真跑再写。 → 4 个实验实操验证（headless 跑通文件整理/AGENTS.md/MCP/SKILL），产出《实操记录》作逐字稿底稿，口播全部基于实测行为。实操还挖出 3 个”坑变素材”：V4-Flash 无视觉但诚实拒绝编造 / SKILL 中文名不识别 / headless 无审批时 rename 退化 copy——真实边界比完美演示更有教学价值。

2. Cowork 接口文件闭环（跨会话协作）

WorkBuddy ↔ Claude Code 用「指令文档 → 回执文档」模式协作：指令带三项决策，回执带执行结果 + 字面偏差说明 + 需确认事项 + 反对路径。决策人（跳蛛）验收后主会话才收尾下游任务。红线条款（未获指令不动图不动会话）避免双写冲突。

3. 对标移植三板斧

拿对标文档（同结构教程）时：① 提取目录对齐章节骨架；② 逐段读对标正文摸深度标准（字数/结构/钩子模式）；③ 对标图内容消化进正文而非贴图了事（用户纠偏：对标是素材不是配图）。

dws 协作坑全记录（技术资产）

#坑解法
1并发写文档unable to write concurrently + 块漂移（blockId 对不上/内容错位）。必须全程串行，一条 set -e 链最稳
2--text 含英文双引号dws 内部转义解析报错，去掉或用中文引号「」『』
3block insert 多段顺序--ref-block --where after 新块紧跟参照块；连续插多段要倒序或每次重新定位新 blockId
4内联图片定位钉钉内联图在 block list 中是空 paragraph（非 image 块），判断顺序用 doc read 找 ![](...)
5批注框插入实际是 container 块 subType=colorBlocks；用 --content-format jsonml + 完整 JSONML（模板在 /tmp/callout_*.json，照抄作者手调块）；shell 转义走临时文件 $(cat) 最稳
6media insert三步一体化直连执行即可；勿用管道吞返回值
7dsh plugin 命令语法dsh plugin --profile web <args>（plugin 是一级子命令，—profile 是它的 flag）；写成 dsh --profile web plugin 报 profile not specified
8headless 环境限制无审批通道（PowerShell 初始化失败）、stdout 偶发丢失（exit 1 但操作已落盘）、V4-Flash 无视觉。完整演示必须 Web UI

协作红线与偏好

  • 隐私：口播不出现第三方创作者人名，引素材说”网上有人/有人整理”
  • 分段：一段一要点，写完用户会手动拆分段优化观感——直接写短段省一道工序
  • 「（跳）」：跳蛛先生的署名标识（他负责写的章节），不是待补标记——动结构前先问
  • 口播纯文字：不加花字/录屏占位/aroll/broll 标注（剪辑层是用户私有工作流）
  • 事实核实：命令/版本号/价格先搜索核实再写；模型能力没验证不编造
