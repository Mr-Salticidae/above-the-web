载体默认语义反噬（题眼被载体的常识含义盖掉）

入档：2026-08-06 来源：2026-08-06 PB 闪电战「时间贫困」· 回转寿司图未夺冠 性质：闪电战冷读者校准律_v1 的方向侧补全——冷读者律管「读不读得到」，本律管「读到的是不是反的」 验证状态：⚠️ 首次发现（单案），暂时性结论。v1.1 补：三问是必要不充分条件（2026-08-07 首次实战三问全过、图仍零票）——见文末回填段

一句话总结

把抽象题面嫁接到日常载体时，先查这个载体在观众心里的默认语义。如果它跟题眼方向相反，prompt 层的细节锁扳不回来——只能换载体。

案例

题面「时间贫困」。作者解读：AIGC 工具出得太快，人人都在追新工具，没时间做别的。

选定载体：回转寿司。逻辑是「传送带不断送来新盘子 = 新工具不断出现，上一个还没学会」。

prompt 里下了明确的题眼锁：

untouched perfect food, none of them eaten

盘子里的东西没动过，表示「来不及」。

MJ 执行了这道锁——出图里堆叠的盘子确实还夹着寿司和饭。

但图仍然失败。 冷读者第一眼读到的是：

一个男人在回转寿司店，面前堆着两摞很高的盘子 → 这人吃了很多

因为在回转寿司这个载体里，盘塔是一个全民预装的强符号，含义是「我吃完了这么多」= 战果、丰足、满足——跟「贫困」正好相反。

原理：细节锁改不动集体常识

层内容谁在控制
载体默认语义盘塔 = 吃了很多观众的集体常识，prompt 碰不到
prompt 细节锁盘里还有食物 = 没吃作者，模型能执行

观众不会去数哪盘有食物、哪盘是空的。他只看到**「塔很高」这一个形状**，然后调用常识给它赋义。

细节锁在 prompt 层成立、在模型层被执行，却在观看层失效——因为它要求观众做一次他根本不会做的二次核对。

→ 载体的默认语义是先验，细节是后验。0.5 秒里只有先验起作用。

与冷读者律的关系：两把尺，三种结局

冷读者读到什么例结局
读不到（零信息）「好看的云 / 袋子」· 真空天空零票
读到反的（负信息）「这人吃了很多」· 回转寿司比零票更糟
读到对的「笼空了」· 空鸟笼冠军

零信息只是没得分；负信息是主动往反方向送分——图在替对手说话。

操作对策 ·「载体三问」

定载体时跑，不是出图后跑。 对画面里最大的那个形状问三句：

  1. 这个东西在观众心里默认是什么意思？（不是我想让它是什么意思）
  2. 这个默认含义跟题眼是同向、无关、还是相反？
  3. 如果相反——能不能只靠改画面结构扳回来？扳不回来就换载体，不要靠加细节。

回测本案：盘塔 → 默认「吃了很多」→ 相反 → 该在写 prompt 之前就换掉，而不是靠 untouched 去救。

换载体不必推倒重来：载体常常只有一半是反的

把载体拆成**「流动 / 积累 / 消耗」等可分离的动作**，逐个查方向，留同向的、删反向的。

本案拆解：

载体动作对应题眼方向处置
传送带「不断送来」新工具不断出现同向 ✅留
盘塔「堆起来」已完成 / 丰足相反 ❌删

改法：他面前的桌面空着、干净的、一盘都没拿下来，传送带满载流过。「全都来不及拿」才跟「匮乏」同向。

这是一道护栏，装在「嫁接陌生载体」上

我没想到+我做不到双触发器_v1 把「题面嫁接到陌生载体」列为”我没想到”的主要触发方式。本律是这条操作的护栏：

嫁接载体默认语义与题眼结果
「再少年」→ 墓碑死亡、思念、不可逆同向获奖（R2）
「时间贫困」→ 盘塔丰足、战果相反反噬

嫁接越出人意料，越要查方向。「我没想到」和「我看反了」之间只隔一道默认语义。

⚠️ v1.1 回填：载体三问是必要不充分条件（2026-08-07）

案情：次日「最后一夜」闪电战，本律首次实战应用。载体选真空管阵列（只剩一根还亮着），载体三问全部通过——默认语义「快熄灭了 / 最后的」与题眼同向，无反噬。

结果：仍然零票。

结论：三问只能保证方向不错，不能保证信息够。它是一道排除性闸门，不是通行证。

过了三问之后还要过两关：

关卡问什么出处
载体三问（本律）载体默认语义方向对不对？本文
主语关这张图里谁要失去什么？闪电战冷读者校准律_v1 v1.2 第四分型
事件关有人正在做一件**“不该在这个处境里做”**的事吗？获奖图复盘方法论合集_活合集 第 42 条

本案是「过了第一关，倒在第二、三关」：灯管阵列方向全对，但它是个无主语的抽象状态，画面里没有人在做任何事。

→ 本律的定位因此收窄：它是选载体阶段的排除工具，不是选方向的充分依据。别因为三问过了就以为方向成立。

适用边界

  • ✅ 闪电战 / 同行互投 / 任何 0.5 秒决断的赛场
  • ✅ 封面、海报、信息流首图——同样是先验主导
  • ⚠️ 展示线（长图文、画册）容许观众二次核对，反噬可被文案救回，但仍然是减分
  • ❌ 不适用于载体本身就是主题的作品（如「吃播」题去画回转寿司）——此时默认语义就是题眼

微调的边界

核心叙事意象不可微调。微调前问："这个特征如果没了，主题还成立吗？"——不成立就不动。

 方法论与洞察

隐喻身体化升级法

把外部隐喻物从"主体身边的物件"升级为"主体身体本身的属性"——隐喻从"事件"升级为"内在状态",视觉荒诞度与概念密度同步翻倍。
