作品线与配方线,外壳不串味

入档:2026-08-03 触发:56_满堂 正文写成「这张好在哪」的画面分析文,被作者一句「太正式了,参考之前衔风等系列」否掉 主线作品来源:{AIGC工作站}/56_满堂_90s港片古装人像_作品图文/03_发布文案/小红书_发布文案.md 验证状态:⭐⭐ 二次验证(沿用侧 + 偏离被否侧),依据为作者主观判定,非平台数据

一句话

同一个账号里,作品线和配方线的文案外壳不能混。作品线只给画面和第一人称的声音——散文诗,她自己在说话,视觉机制留档不进正文;配方线才在正文末尾给可复跑配方。拿作品线的图配教程线的文,读起来就是「太正式」。

案例:同一张图,两种壳

《满堂》(90s 港片古装人像)正文初稿:

AI 出的古装人像有个通病:太「正」了。
……这张不一样的地方,其实不在她脸上,在镜头站的位置。
你看左边那片红色虚影,那不是败笔,那是挡在镜头前的另一个人。
这是 90 年代港片的老招数——长焦压过去,大光圈把背后的灯笼化成一团团暖光……

机制讲得对,但被一句「太正式了」否掉。改写后:

满堂的灯都亮着,
没有一盏,是为我点的。

有人从我跟前走过去,
红影一晃,
把你挡了半边。

我本不该回头的。
是风先动的手——
它掀了我的碎发,
我就顺着那阵风,
看了过来。
……
满堂的人,满堂的灯,
只有我,先回了头。

同一处「前景挡镜头」的观察,分析文里是论据,散文诗里变成她被人挡了一下——机制没丢,身份换了。

三处要一起换,只改正文不够

位置教程口吻(错)作品口吻(对)
标题这一眼的高级感不在脸上,在镜头站的位置满堂的灯都亮着,没有一盏是为她点的
正文三段式分析:通病 → 这张的不同 → 机制第一人称散文诗,短句、留白、不解释
机制写进正文当论据降级成评论区第一条,口语一句带过;或只留在项目内的拆解文档

别把机制彻底删掉——它是好东西,只是不该占正文。放评论区还多一个互动位。

判定:这条属于哪条线

动笔前两问(第一问见 外来prompt不做配方物料_v1):

  1. prompt 是谁的? 外来 → 只能是作品线,配方线的壳直接出局。
  2. 有没有可分发的方法? 有(自写 / 公开来源 prompt、可复跑流程) → 配方线,末尾给配方;没有 → 作品线,只给画面和声音。

线定了,文风就定了,不由「我这次想讲多少」决定。

证据与它的限度

沿用侧:39_晴枝(2026-06-11,散文诗四节对应四图)、48_即兴抽卡 十一组(每组一篇「简介_第一人称散文诗」)——作品线一直是这个体例。 偏离被否侧:56_满堂 写成分析文,当场被否。

限度(重要):两侧证据都是作者主观验收,没有任何 A/B 或平台数据。这条只能说明「偏离体例作者不认」,不能说明「散文诗带来更好流量」。要说流量,按 复盘事实先行原则_v1,得先有对照数据。

反例 / 边界

  • 配方线正文末尾给可复跑配方是对的,不要反向套用本条把配方删掉——51 项目那条「sref 管皮,散文管心,风格词管样子」+ 可粘贴配方,正是它该有的样子。
  • 平台差异未验证:本条证据全部来自小红书 / 短视频平台的图文与简介。
  • 作品线里也可以有信息,但走图注 / 评论区 / 项目文档,不走正文。
