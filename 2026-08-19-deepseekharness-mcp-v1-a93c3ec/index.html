DeepSeek Harness 教程收口日 · MCP 改写与录屏重录交接复盘

日期：2026-08-19 · 项目：钉钉文档《DeepSeek Harness全案实测，保姆级教程》（node b9Y4gmKWrPgaA1omhewrkL2YJGXn6lpz） 协作方：跳蛛先生（决策）、桓（改写/盘点/交接文档/FAQ补写）、Claude Code（录屏执行方，待回执） 状态：（跳）标注全部清零；录屏 25 条交接待回执；学员共创 8 节进行中

一句话律

转述链衰减律——执行前回原始材料：需求每经一手转述就漂移一分，「C 类录屏需要 Mac 设备」这条约束在三轮对话里被反复确认为真，最后读一遍 MAC OS 章节逐字稿原文（全是浏览器打开三方成品的演示）即一锤消解。对”执行前提”的否定结论，永远以原始材料为准，不以几个人的转述一致为准。

弧线速览

  1. MCP 段落小白化：能力3 原文术语密集（统一接口/声明/热重载），改写为实例驱动五段（没装会怎样 → 加几行字告诉它三件事 → 14 个工具+读文件实例反推规律 → 社区生态 → 过渡钩子），update 原块 + 逆序 insert 落库。
  2. 过渡钩子纠错：原钩子指向 SKILL，实际能力4 是斜杠命令（SKILL 在能力5）——写章节钩子前没核对文档实际结构，沿用原文案假设所致。
  3. 文档定位变更：全文档 = 视频录制逐字稿，最终只留图片 + 剪辑直用视频；旧录屏因鼠标指针太小全部重录。
  4. 25 条录屏三分类盘点：A 类脚本管线 6 条（rec_lib.js 假光标 18px→30px 是”鼠标太小”根因）、B 类真实录屏 10 条（先调 Windows 系统指针）、C 类 9 条。
  5. C 类 Mac 误判三连改：Mac 端另录（协调另一台设备）→ 执行人是跳蛛本人（配了 Mac）→ 根本不需要 Mac（9 条全是浏览器成品横评演示，归 Claude Code 本机）。交接文档 C 类整节重写三次。
  6. FAQ 节补写：「常见问题解决(跳)」原只有对标截图占位；读对标截图（6 条排错）→ 口播化改写（诊断+解法，不堆命令）→ 替换占位块、清对标图与红色高亮。

提炼的规律

1. 转述链衰减律（本次头号教训）

C 类「需要 Mac」的演化链：跳蛛转述同事安排（Mac 另录）→ 自我修正（执行人是自己，配了 Mac）→ 第三轮才想起读原文 → 9 条全是浏览器成品演示。三轮里没有任何人说错话，但虚构约束越滚越实。规律：交接/协作链上，凡涉及设备、账号、权限这类”执行前提”，接手方应索取原始材料（逐字稿、原始需求表）直接核对，而不是核对各方转述是否一致——转述一致只说明大家读了同一份转述。

2. 章节钩子先核对实际结构再写

MCP 末段钩子指向 SKILL 的错误，根因是沿用原文案里”接下来是 XX”的假设。规律：写任何章节过渡钩子前，先 block list 把全部 heading 拉出来核对顺序，钩子指向的是文档事实不是记忆。

3. 对标截图是规格说明，不是配图

FAQ 节的对标截图给出的是「问题清单 + 排序 + 详略标准」，正确用法是消化成口播正文（每条一句诊断+一句解法），而不是把截图留在文档里充数。与 08-18 复盘”对标图消化进正文”同律，本次是其在”占位节补写”场景的再验证。

4. 逐字稿文档的定位变更要全链路同步

「只留图片+剪辑直用视频」的新定位一出，旧视频附件的处置（全部重录替换）、图片保留原则、甚至鼠标指针大小这类制作参数都成为文档工程的一等公民。规律：交付物形态变更时，把”哪些资产留、哪些资产换、按什么规格换”列成显式清单进交接文档，不要散落在对话里。

dws 协作坑补充（接 08-18 复盘的 8 坑，本文 +3）

#坑解法
9block update --text 含 \n\n 只保留首段钉钉 paragraph 块把空行当段落分隔，后续段静默丢弃（不报错）。多段内容要么单 \n 连排，要么拆多块 insert
10block insert/update 只能产 paragraph 块CLI 无法创建/恢复 heading 层级；对 heading 块 update 会降级为 paragraph且不可逆（CLI 侧）。需要标题层级时最后手动在钉钉 Web 里补
11block list 的正文在 element.paragraph.text与 08-18 坑 4 同源：heading 正文在 element.heading.text，attachment/image 是空 paragraph；搜索要用对应子对象字段，不然零命中误判”块不存在”

另：block delete 非交互环境必须加 --yes（先 --dry-run 预览更稳）；删除内联图片 = 删其宿主空 paragraph 块。
