# 安全策略

「蛛网之上」的源码公开在本仓库，线上跑着账号与任务服务（`tiaozhuxiansheng.com/api/`）。发现安全问题时，请按下面的方式私下告知，不要直接开公开 issue。

## 如何报告

1. 打开本仓库的 **Security** 页签，点 **Report a vulnerability**，用 GitHub 的私密漏洞报告提交。
2. 写清楚：受影响的地址或文件、复现步骤、你观察到的结果与预期结果。能附上最小复现最好。
3. 请不要在报告里附带任何真实用户的数据；验证时用自己注册的测试账号。

收到后会先确认能否复现，再在私密通道里同步修复进度。修复上线后，如果你愿意，会在提交说明里致谢。

## 范围

在范围内：

- 主站 `tiaozhuxiansheng.com` 与账号服务 `/api/`（登录、注册、重置密码、任务认领、管理台权限）
- 本仓库中的构建脚本与 GitHub Actions 工作流

不在范围内：

- 快讯子站、GitHub Pages 镜像上的纯静态内容排版问题
- 依赖第三方平台（GitHub、Cloudflare、B 站等）自身的问题，请直接报给对应平台
- 需要物理接触设备、社会工程或大规模流量压测才能成立的问题

## 仓库侧的约定

- 密钥、服务器地址、登录态一律放在仓库 Actions secrets 里，不写进代码或文档；清单见 README「部署」一节。
- 服务端 `.env`、SQLite 数据库、曲库音频都不进 git（见 `.gitignore`）。
- 工作流只由 `push`、定时与手动触发，不接受来自 fork 的 `pull_request_target`，外部 PR 拿不到任何 secret。
