# 任务书月度产出统计

## 使用

管理员进入「任务 → 月度统计与对账」或管理台「月度统计」，选择月份、交付月或打款月口径，按需筛选承接人。页面提供任务数、可识别约定金额、待核实项、当前已结款数、承接人汇总、成稿链接与明细；点击「导出 CSV 对账单」留存核查材料。

任务书列表页首屏新增「新建任务书 / 管理任务 / 月度统计与对账」快捷入口；管理台各页标题区突出「新建任务书」主按钮（新建页本身除外）。入口可见，操作仍要求发布方账号权限。

## 统计口径

- 按北京时间（UTC+8）归月，每份任务计一项，不按附件数或提交次数计数。
- 交付月读取 `deliveredAt`，打款月读取 `paidAt`，包含已下架任务。无日期的相关历史记录另列，不使用发布日期或更新时间猜测归属月份。
- 交付表示已有交付记录，不代表验收通过；当前状态、金额均为查询时的值，不是月末冻结账本。系统状态回退可能清除日期，因此本页不能重建被清除的历史流水。
- 金额使用接口返回的当前有效报酬（优先调整后金额），仅明确的人民币总额计入，使用整数分累加。区间、单价、附加费用及无法识别的文本单列核实，不算成零元。该金额不等同于银行实付金额。
- 承接账号按 ID 分组，手填承接人按名字分组；同名手填记录需人工核对。
- 日期缺失记录跨月份显示，并标注未计入本月；CSV 包含同一筛选下的月度明细及日期缺失记录，不重复计入合计。
- CSV 使用 UTF-8 BOM，保留报酬原文、原价、调价事由、日期、成稿链接及核实事项，并转义电子表格公式前缀。

## 实现与验证

复用受管理员权限保护的 `/api/admin/overview`，无数据库迁移。统计函数位于 `src/lib/task-monthly.mjs`，页面位于 `src/pages/admin/tasks/monthly.astro`。

运行 `npm test` 校验跨月与跨年通用归月逻辑、金额解析、缺失日期、下架任务、同名账号、CSV 转义与筛选；运行 `npm run build` 完成内容同步、YAML 清洗、静态站构建和搜索索引。发布后管理员应对照原始交付和打款凭证核查一个已知月份。

本次本地验证：23 项测试通过；4 个改动页面及布局通过 Astro 编译器检查，内联脚本通过编译检查；正式构建命令通过，生成 590 个页面，搜索索引覆盖 598 个页面。

首次直接运行 Astro 时，未经过同步脚本清洗的知识库缓存含有未加引号的双链元信息，导致 YAML 解析失败。正式命令中的 `scripts/sync-content.mjs` 已有归一化处理，重新按完整流程执行后解决。不要跳过同步清洗步骤对原始知识库缓存直接构建。
