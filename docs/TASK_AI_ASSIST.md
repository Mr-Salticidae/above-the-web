# 任务书系统的 AI 辅助填写

## 这次要解决的是什么

任务书系统本身跑得通，卡的是「填」这一步。两处阻力都不在功能上，在人面对空白框的那一刻：

| 谁 | 卡在哪 | 结果 |
| --- | --- | --- |
| 发布方 | 新建任务书要填七个小节，还要想链接后缀、把「8 月 20 号」换算成 `2026-08-20` | 宁可回去改 markdown 再等一轮构建 |
| 接单的人 | 认领面板给一个空的「自荐说明」框，不知道该写什么、怕写得不像样 | 看完任务书就走了，或者只写一句「我想接」 |

所以这次做的不是新功能，是把两处的入口都换成一句大白话：**说人话 → 它把表单填好 → 人过一眼再改**。

顺带把另一件事也堵上：写到一半误关页面、登录过期，内容不该就这么没了。

## 做了什么

### 一、发布方：说一句话，出一份任务书

页面：`/admin/tasks/new/`

输入「找人写一篇 OJO 的工具评测教程，8 月 20 号前交，150 元税前，会员我出」，
点「帮我拟一份 →」，标题、摘要、报酬、截止日期、链接后缀、七节骨架的正文一并落进下面的表单。

- **框里备着三句现成的例句**，点一下填进去改两个字就能用——空白框最劝退。
- 表单里已经有东西时，按钮改口成「按这段话再改一版 →」：这时候点它是**改**，不是重写。
  没被要求改的部分尽量原样留着。
- Ctrl / ⌘ + Enter 直接跑。
- 「填入模板」「预览正文」照旧，另加一个「清空重来」。

### 二、接单的人：说一句话，出一份自荐

页面：任务详情页的认领面板（`/tasks/<slug>/` 与 `/tasks/detail/?slug=`）

输入「这工具我用过一阵，想按装用坑三段写，下周三前能交」，点「帮我理一理 →」，
出来一段按「怎么做 / 做过什么 / 什么时候能交」组织好的自荐说明，直接落进自荐框。

例句给的是**带括号的骨架**（「我打算这么做：（两句话说清怎么做）。做过的同类：（贴一个链接）。」），
不是编好的履历——一键填进去就能提交的假经历，发布方一问就穿帮。

### 三、草稿留在本机

新建任务书和认领申请的输入随手存进 `localStorage`（`atw-draft:*`，14 天过期）。
离开再回来自动带回，并说清是几时的东西、留一个「不要，清空」。提交成功就清掉。

这一条与 AI 无关，没开 AI 也在。

## 守着的几条线

- **AI 只填表单，不替人提交。** 生成完东西还在框里，改不改、发不发都是人说了算。
  库里没有任何一条路径是模型直接写进去的。
- **不编事实。** 报酬、截止日期、标杆链接只有发布方知道；做过什么作品、什么时候有空只有申请人知道。
  没说的一律不填，任务书正文里写成「（待补：……）」占位，并在框底下列一条提醒去补。
- **服务端把模型输出当草稿洗一遍**：截到字段上限、日期不合 `YYYY-MM-DD` 就丢掉、
  链接后缀按站内那套规则重新规范化。「模型说了什么」和「什么能落进表单」是两件事。
- **隐私边界照旧。** 送进模型的只有任务书本身、公开资料（昵称 / 简介）和用户自己写的那段话。
  联系方式、收款方式、邮箱一概不带。
- **每个账号每小时 30 次。** 超了只堵 AI 这个入口，手填和提交一点不受影响。
- **没配 key 就当它不存在。** `/api/meta` 的 `aiAssist` 为 `false` 时，页面上连按钮都不摆出来，
  手填那条路一点没变。模型那头出岔子回 502 加一句「手填也能发」，对方的原话只进日志。

## 为什么服务端要存一份 `outline`

写自荐说明得知道这活儿到底要干什么，可 md 任务书的正文在 git 里，平台服务读不到——
库里的 `body` 只有站内新建的那批才有。

清单（`/tasks/index.json`）本来就是两边对接的那个构建产物，于是让它顺带捎一段正文纯文本节选
（去掉代码块、图片、链接语法，截到 2400 字），同步时写进 `tasks.outline`。
只读不改、不进任何公开接口，同步逻辑里也留了退路：清单里没有这个字段（老版本构建产物）
就不动库里已有的那份，不会把它抹成空。

## 怎么配

服务器 `.env`：

```bash
ATW_AI_API_KEY=            # 留空 = 不开这个功能，页面上看不出少了什么
ATW_AI_BASE_URL=https://api.ofox.ai/v1
ATW_AI_MODEL=claude-fable-5
ATW_AI_TIMEOUT_MS=90000
ATW_AI_MAX_TOKENS=4096
ATW_AI_HOURLY_LIMIT=30
```

换供应商只改 `BASE_URL` / `MODEL`，前提是对方支持 `response_format.json_schema`——
不支持的话模型会返回散文，结构化字段解析不出来。
