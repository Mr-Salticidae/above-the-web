白底上的白事件等于没发生

来源：65_过风 项目 2026-08-25 · LibTV 直连 Seedance 2.5 · 30s / 1080p 单条 性质：设计缺陷，不是模型失败。模型完全照做了，是我选错了事件。

一句话

选「片子里发生什么」之前，先看底图的影调。 事件本身的亮度必须跟底图反着来——高调片的事件要暗或高对比， 只有暗调片才能用白色的事件（白雾、白烟、呼出的白气）。

触发案例

原图是一张冷白高调的雪雾人像：背景是一整片白到看不出轮廓的雾， 最暗的地方是头发，也没到纯黑。

设计的核心事件是「她呼出一口白气，白气悬在唇前不散」， prompt 里给了正面的物理解释（空气冷到没有一丝风把它带走）。

模型完全执行了。 唇左侧 200×160 区域逐秒亮度：

t= 8~13s   92.2 → 88.3        （呼气前的本底）
t=14s      87.6                （谷底）
t=15s      92.0                （白气出现，起跳）
t=18~27s   93.5 ~ 94.8         （悬停，稳定不散）

出现时机、悬停时长、不散——全部按 prompt 走。

但成片整幅看过去几乎看不见，必须裁到唇部局部才辨认得出。 主创审片的判语是「画面无趣、质感不强」。

根因

白气在现实里之所以可见，是因为它背靠的是暗背景——冬天的黑外套、深色的树林、夜里的路灯。 这张底图是一整片冷白雾原，白对白，对比度接近零。

执行成功 ≠ 可见。 这两件事之间隔着一个影调。

落地

写 prompt 之前先做这一步：把底图的高对比元素列出来，动能只能交给它们。

以本项目为例，高调白底上只有三样东西看得见：

元素为什么看得见
黑色短发全图唯一接近黑的东西，任何位移都清晰
珍珠的硬高光亮点是「锐」的，在柔白底上是形状而不是亮度
白绒毛的单根纤维靠结构而非亮度取胜——成百上千根各自翻卷，白底上看得见的是纹理变化

改版后把 15 秒的动能全部交给这三样（一阵风穿过：绒毛翻卷 → 碎发扫脸 → 珠串相碰）， 主创一次过审。

对照检查表

底图影调可用的事件不可用
高调 / 白底深色主体的位移、硬高光的闪动、结构性纹理变化（纤维/发丝/织物）白雾、白烟、呼出的白气、雪花、逆光尘埃
暗调 / 黑底白雾、白烟、呼出的白气、火光、水面反光、逆光尘埃黑色主体在暗部里的小位移
中间调两边都行，但要给事件一个明确的衬底（写清楚它出现在什么东西前面）

与既有律的关系

  • 这条是 图生视频_ForwardOnly原则_v1 的前置一步。 ForwardOnly 管「这个动作能不能从源图向前发展」，本条管「这个事件观众看不看得见」。 顺序是：先过可见性，再过 ForwardOnly。 一个不可见的事件即使完全合法，也是废镜。
  • 与 Seedance2_5_行为规律_v1 §一「把切点安排在暗部占满的那一帧」是同一个机制的两面： 那条用「看不见」来藏东西，本条提醒「看不见」也会把你要给的东西一起藏掉。 本项目一度想把该条的「暗部占满」改写成「白场占满」来藏切点—— 后来证明分段本身不成立（见该档 §一），但那个改写方向本身是对的。

验证状态

⚠️ 首次（1 次项目内验证，含亮度量化数据）。 两侧都只测了高调这一半——「暗调底上白色事件成立」是常识与既有素材的推断，本项目没有测过。
