双工具分工 · nano 锁脸 + MJ 摄影质感

入档:2026-05-19 触发:23 项目《再少年》5/17 晚 MJ「女鬼事件」后的工具分工决策 性质:跨场景出图的双工具协作方案——角色一致性 与 摄影质感 是两个工具,不应该是一个 关联:AI形象图工作流分层_niji5+Nano_v2 / nano跨场景三变量发现_v1 / 识别工具天花板的时机_v1

一句话总结

叙事型项目里,nano 负责”凡是有主角脸的镜头”,MJ 负责”环境/物件/不露脸的氛围镜”——两个工具同时跑,各自做自己最强的事。MJ 没有 IPAdapter,跨场景锁脸=物理上限;nano 摄影质感稳但容易”AI 味”。

工具能力分工表

维度nanoMJ
跨场景同一角色✅✅ 三变量齐全时强❌ 无 IPAdapter,跨场景必漂移
摄影质感✅ 中(易”AI 数字味”)✅✅ 强(胶片/景深/光影)
多元素组合✅ 中✅✅ 强
控制精度✅✅ 强(听 prompt)✅ 中(有自我审美)
抽卡成本低中
失败模式角色漂移”AI 怪图”/语义乱跑

→ 同一项目里两个工具的能力分布是互补的,不是替代。

分工边界(实战公式)

是否有主角脸出现?
   │
   ├── 是 → nano(三变量齐全,详见 nano跨场景三变量发现)
   │
   └── 否 → MJ(moodboard + 摄影风格关键词,自由发挥)

关键约束:

  • ✅ 同一镜头不要混用两个工具(出图阶段)
  • ✅ 在 plan 阶段就标好每镜的工具归属
  • ❌ 不要在 nano 跑不出来的时候”试试 MJ”——MJ 没有角色一致性,只会拖时间

实战案例 · 23 项目

镜头内容工具原因
S01屋檐空镜MJ无人脸,要 MJ 摄影质感
S02翻照片(手部特写)MJ不露主角脸
S03-S07V1 + Chorus 1(主角各角度)nano全部有脸

→ nano 占主导但 MJ 不可替代——这是双工具分工的最稳健形态。

关键失败案例 · MJ 女鬼事件

5/17 晚跑 MJ moodboard 时,prompt 含 blurred young woman in pale hanfu,触发了 MJ 训练数据里**「东方恐怖片关联」**——输出”女鬼”。

根因:

  • MJ 内部对「pale hanfu + blurred + young woman」组合有强先验(贞子/聊斋类联想)
  • 这不是 prompt 不够好,是工具的内部审美倾向

修复:

  • ❌ 不在 MJ 上死磕调 prompt
  • ✅ 把所有需要主角脸的镜头切到 nano
  • ✅ MJ 只跑「不需要锁脸 + 不会触发恐怖片关联」的环境镜

→ 双工具分工的本质是「绕开各自的内部审美雷区」。

工程协作要点

1. 出图阶段并发

nano 和 MJ 跑在两个独立窗口/会话,互不等待。 跳蛛先生这边:nano 主跑(因为占比大),MJ 副跑(批量出 5-6 张备选)。

2. 风格统一(后处理)

两个工具出图后,用同一个调色脚本统一色调(50% LAB histogram matching 到基准图)。 → 双工具出图风格差异在调色阶段 80% 被抹平,剩 20% 由可灵图生视频的运动模糊进一步抹平。

3. plan 阶段标注

{
  "shot": "S03",
  "tool": "nano",
  "reference": "基准图.png",
  ...
},
{
  "shot": "S08",
  "tool": "MJ",
  "moodboard": "清冷古风_v2",
  ...
}

→ plan 文档里就锁定工具,避免出图阶段反复犹豫。

反向陷阱

❌ 陷阱 1 · 「我换一个工具试试」

副会话最容易犯——nano 跑不出来某个镜头时,直觉建议「换 MJ 试试」。 这破坏了分工边界——MJ 不能锁脸,换了等于丢角色一致性。

❌ 陷阱 2 · 「同一镜头两个工具都跑」

浪费时间且产出无法直接对齐——两套出图色调/构图都不一样,选哪个都得调色。 正确做法:plan 阶段就决定工具归属,只跑一个。

❌ 陷阱 3 · 「nano 出图后用 MJ 重绘加质感」

这是 niji5+Nano 分层工作流的逻辑,但叙事型 MV 不适用——重绘会破坏角色一致性。 分层工作流只适合「单图精修」,不适合「跨场景一致性出图」。

与 niji5+Nano 分层工作流的区别

维度niji5+Nano 分层nano+MJ 分工
适用场景单图精修(冠军形象图)跨场景叙事(MV)
协作方式串行(先 niji5,后 nano)并发(各跑各的)
角色一致性不需要必需
工具调用关系A 出图 → B 改 A 的图A/B 各自完成各自的镜头

→ 同样是「双工具」但工作流逻辑完全不同,不要混淆。

跨场景适用性

已验证适用

  • ✅ 叙事型 MV(23 项目)
  • ✅ 任何有跨场景主角的项目

推测适用

  • 🔄 短剧/MV(5+ 镜)
  • 🔄 漫画分镜(角色一致性强需求)
  • 🔄 IP 形象推广素材(多视角同一角色)

不适用

  • ❌ 单图项目(用 niji5+Nano 分层即可)
  • ❌ 纯环境镜项目(MJ 一个工具就够)
