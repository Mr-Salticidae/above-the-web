AI 平台定价与可及性观察台账

立项:2026-07-31 触发:即梦 Seedance 2.5 内测报价(¥80 / 30s)引发的一次追查。查到最后发现真问题不在价格,在于跨区通道被主动封锁——而这个结论,是在我自己两轮错误归因之后才浮出来的。 定位:长期台账,不是一次性复盘。 每遇一个平台的定价 / 可及性动作就立一案,按同一套方法测、同一套判据分级。 关联:即梦Dreamina跨区定价实测_同产品双账号对照_v1 / 积分制比价先校购买力律_v1 / 伪开源三查律_v1

为什么要台账化,而不是每次写一篇复盘

因为单次事件几乎必然归因错误。本次追查里,连续错了两轮:

轮次我的结论错在哪
v0「Seedance 2.5 贵但不出格,对标 Veo 顶配」拿国际 API 价目表去对国内内测价,两张单子
v1「国内积分比国际贵 38.9%」只比积分标价,没核对一个积分买到什么
v1.1「国内实际贵 14.4%,税前 8%」目前站得住

两次都是比价口径错误,不是数据错误。这类错误的特征是:每一步都看着合理,结论却是反的,而且单看一个案子发现不了——只有把多个案子放在同一套口径下横向比,口径漏洞才会暴露。

所以这个项目的核心资产不是”骂了哪几家”,而是一套越用越硬的测量口径。

观察方法(硬规范,每次立案必须遵守)

1 · 比到手成本,不比标价 ⭐

积分 / 点数 / credits 不是货币,是厂商自定的中间计量单位,两个区服、两个套餐之间购买力可以完全不同。必须算到「每条成品实付多少钱」这一层。详见 积分制比价先校购买力律_v1。

2 · 同产品、同渠道、同规格

  • C 端积分价 ↔ C 端积分价;B 端 API 价 ↔ B 端 API 价。零售价和批发价对比是无效对比(正常 SaaS 零售溢价 40%+,与国别无关)。
  • 分辨率 / 时长 / 宽高比 / 生成条数必须逐项对齐,任一项不同则结论作废。

3 · 一手截图优先于公开检索

本次三轮纠错全部由一手证据推动,检索一次都没帮上忙。原因:搜索索引偏英文与美区,国内 C 端定价和内测信息本就抓不全,越搜越容易拿到国际价目表——也就是 v0 错误的直接来源。

账号截图 > 从业者口述 > 媒体报道 > 搜索摘要。

4 · 区分「合规环境施加」与「厂商选择」

这是最容易被情绪吃掉的一步,也是判断力的分水岭:

  • 环境施加(不记在厂商账上):内容审核基建成本、备案与安全评估、受出口管制的算力单价、数据出境限制导致的功能阉割。
  • 厂商选择(记在厂商账上):约束给定之后,如何分配负担。是按平价定国内把差额自己吃掉,还是转嫁给本土用户?是留一条合规的跨区通道,还是主动建墙?

把结构性约束读成主观恶意,会让你对这家公司下一步做什么完全失去预测力。台账要的是预测力,不是出气。

5 · 结论必须分三档,不许混

成立 / 已推翻 / 待验证,每档独立成栏。被推翻的结论要留在档里(不许删),因为「我曾经怎么错的」本身就是方法论资产——见上文归因表。

分级判据:什么才算「离谱」

级别判据例
A · 值得立案主动封锁跨区套利(建墙);对本土市场反向定价(违反低收入市场定价更低的通行惯例);同价不同质且不主动告知即梦国际侧无中国大陆区域选项 + 发卡行国别级拦截
B · 记一笔涨价挤压从业者;积分静默贬值;配额 / 有效期悄悄改;会员权益缩水即梦 2026-04 涨价致 AI 短剧从业者被挤压(东方财富报道)
C · 不算单纯贵;前沿模型溢价;合规导致的功能阉割;正常零售批发价差Seedance 2.5 ¥80/30s 本身;国内版过滤更重

C 级不立案是这套判据最重要的部分。前沿溢价是暂时的(历史窗口 6–18 个月),合规阉割不是厂商写的规则。把 C 级当 A 级喊,会让真正的 A 级失去可信度。

每次立案的采集清单

照着抄,缺项就是结论有洞:

  1. 两边的购买页截图(档位 × 单价,尽量取相同数量档做直接对价)
  2. 两边的生成参数栏截图(同规格下的单次消耗)——这一项最常漏,漏了必然算错
  3. 会员 / 非会员两种身份的价格(界面标 VIP 的数字可能已含折扣)
  4. 默认生成条数(有的界面显式给,有的不给,不给的要手动确认)
  5. 区域 / 国家选项列表(有无本地区)
  6. 支付失败时的原始报错与卡种信息(币种、发卡行、账单地址、同卡在别家是否可用)
  7. 官方 API 价目表(用于和 C 端零售价互相校验)
  8. 同 prompt 两边各跑一次的原始输出(用于验证质量 / 过滤强度差异)

已提炼的规律

  • ⭐ 积分制比价先校购买力律_v1 —— 积分不是货币,标价差不等于到手差
  • 价差不需要墙来保护 —— 跨境支付摩擦本身就能吃掉 10%–15% 的价差。所以看到墙,就说明护的不是价格,是分区本身(也就是那个不同过滤强度 / 不同能力的版本)。墙的存在比价差的大小信息量更高。
  • 对创作者的实际对策是可迁移性,不是义愤 —— 价差伤不到你,把生产管线绑死在一个「既愿意分区、又有能力围墙」的供应商身上才会。工作流常驻 2–3 个模型,任一供应商都当可替换件。这同时是对「前沿溢价终将蒸发」的免费保险。
