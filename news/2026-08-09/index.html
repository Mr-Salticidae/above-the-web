xAI 发布 Imagine Image 2.0，Arena 评测仅次于 GPT-Image-2

xAI 为 Grok 推出 Imagine Image 2.0 图像生成模型，在 Arena 基准测试中排名第二，仅次于 OpenAI 的 GPT-Image-2。新版本引入 Magic Wand 局部编辑与 Multi-Ref 多参考编辑功能，并支持预设模板。这意味着创作者在 Grok 平台也能获得接近主流模型的图像生成与编辑能力。

Claude Code 8 月 14 日起默认开启 Auto Mode

Anthropic 将于 8 月 14 日把 Claude Code 的 Auto Mode 设为 Pro、Max 和 Team 计划的默认模式。官方测试显示该模式识别危险命令的准确率为 89%，远高于人类审核员的 13.6%。对使用 Claude Code 的开发者而言，工作重心将从写代码进一步转向监控 AI 输出。
