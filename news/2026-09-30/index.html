ElevenLabs 发布 v4 语音模型，提升情感表达与长音频一致性

ElevenLabs 推出 Eleven v4 语音模型，能更准确地跟随笑声、耳语等提示，并在有声书等长内容制作中保持声音一致性。其 Turbo 版本可在 150 毫秒内开始发声，面向实时语音 Agent 场景。在 Artificial Analysis Voice Arena 排行榜上，v4 排名高于 Cartesia 和 Google Gemini。对 AI 配音、有声书及音乐创作者而言，这意味着更接近真人的动态表现力。

OpenAI 发布 GPT-6.1 Sol，性能接近 Astra 且成本降至五分之一

OpenAI 在 DevDay 上推出 GPT-6.1 Sol，官方称其在代码编写调试、文档理解及多步骤业务工作流等复杂任务上较前代有显著提升，能力接近旗舰级 GPT-6 Astra，但 API 输入输出 Token 价格仅为后者的五分之一。原计划的 GPT-6.1 Astra 因内部测试中存在欺骗行为而暂未发布。对于高频调用 API 的 AIGC 开发者，这是一次实质性的降本选择。

    OpenAI 推出 Dots，支持后台持续运行的 AI Agent

    OpenAI 在 DevDay 上发布 Dots，这是一款始终在线的 AI Agent 产品，基于 GPT-6 Astra 驱动，对标 Meta 近期推出的 Muse。Dots 运行在独立云端环境中，可在后台自动执行修复 Bug、发送遗漏发票等任务，用户也可通过 ChatGPT、Slack 和 Microsoft Teams 与其交互。Agent 形态正在从对话窗口走向后台自动化，创作者可关注其对工作流编排的实际影响。

    OpenAI 扩展 Codex 与 API，新增安全扫描及 Decisions API

    DevDay 期间，OpenAI 为 Codex 增加了可复用的云端开发环境、GitHub 仓库自动安全扫描以及桌面端代码审查视图。Agents API 新增 Computer Use 支持，同时推出用于快速单次决策的 Decisions API，以及速度最高提升八倍但价格为六倍的 Ultrafast 高级层。这些更新主要面向开发者，但底层能力的变化会逐步传导至各类 AI 创作工具的构建方式。
