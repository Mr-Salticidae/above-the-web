Claude Opus 5 可从单条 prompt 生成完整 3D 游戏

Anthropic 发布 Claude Opus 5 的 prompt-to-game 能力，仅需一条 prompt 即可生成含几何、纹理、物理甚至音乐的完整 3D 游戏，包括 FPS、卡丁车和类 Minecraft 项目，全部在浏览器中运行。与 GPT-5.6 Sol 和 Kimi K3 对比中细节表现显著领先。这意味着单人原型开发的门槛被进一步拉低。

OpenAI 推出 Presence 让 AI agent 投入企业生产

OpenAI 发布企业级产品 Presence，面向客服和内部工作流，与现有 Workspace Agents 的区别在于支持对外部署，复杂场景由 OpenAI 自家工程师介入。对想用 AI agent 接单或跑自动化工作流的创作者而言，大厂开始提供可落地的托管方案。
