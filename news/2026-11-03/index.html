Anthropic 更新系统提示词，禁止 Claude Code 克隆游戏

Anthropic 更新了 Claude Code 的系统提示词，阻止该工具被用于复刻现有电子游戏。目前复古游戏领域正被大量 AI 生成的反编译和移植作品占据。对创作者而言，用 AI 辅助开发新游戏仍被允许，但直接照搬已有作品的空间正在收窄。

纽约时报等多家媒体起诉 Brave 抓取内容供 AI 使用

纽约时报联合多家出版机构起诉隐私浏览器 Brave，指控其非法抓取受版权保护的内容，并将其分发给 Anthropic、Perplexity 等 AI 客户，同时帮助用户绕过付费墙。这标志着内容方与 AI 数据供应链之间的法律摩擦进一步升级。
