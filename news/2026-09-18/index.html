Claude Code 上线 Projects，支持云端多 Agent 并行协作

Anthropic 重构了 Claude Code 的 Projects 功能，用户可在同一项目下运行多个 Agent。各线程共享记忆、目标与文件库，由协调器分配任务并独立提交 pull request 和运行测试。该 beta 功能目前面向部分 Pro 和 Max 订阅者开放，为需要批量处理代码或文本任务的创作者提供了新的自动化工作流参考。

OpenAI 以 3 亿美元收购图像处理公司 Glass Imaging

据《华尔街日报》报道，OpenAI 已完成对照片处理公司 Glass Imaging 的收购，交易金额为 3 亿美元。此举表明 OpenAI 正将图像计算与处理能力纳入自身技术栈，后续可能会直接影响其图像生成与编辑模型的表现。
