「不够帅 / 不够美」是年龄轴，不是颜系轴

入档:2026-08-05(三角色校园人像定妆 · 男主「校草」三轮迭代) 验证状态:⚠️ 首次发现(含实测证伪)——单角色单项目,但反向版本实际跑图且确认不理想,不是纸面推断。跨角色 / 跨性别待验证 来源:03_prompt模板库/02_案例复盘/2026-08-05_三角色校园人像定妆_MJ复盘_v1.md

一句话

收到”不够帅 / 不够好看”的反馈时,先分轴再改 prompt。 这类反馈九成落在年龄轴(五官没长开 / 显老)或光影轴上,而第一反应几乎总是去改颜系轴(加骨相、堆立体度)——加错轴的结果不是更帅,是更凶。

四条轴

出图”好看度”不对时,先判断问题在哪条轴上,一次只动一条:

轴症状改法
年龄轴五官柔和但没长开(少年感过头)/ 显老改骨骼成熟度与颈肩:a grown-in adult jawline / a solid neck / not a teenager。不动五官形状
颜系轴淡颜 ↔ 浓颜的取向不对改眉骨 / 眼窝深度 / 眉形浓淡。⚠️边际效应极强,过了就从帅变凶
骨架轴头身比、肩宽、脖颈比例不对改体型词 + 画幅参照(broad shoulders filling the width of the frame)
光影轴五官都对但平、糊、没气场改光位与对比(sculpted light across the brow and jaw),不动脸

为什么第一反应总是加错轴

因为**“帅”这个词在语言里最近的可执行邻居是”骨相”**——立体、深邃、有轮廓。所以拿到”不够帅”会本能地往骨相加法走。

但骨相和”帅”不是单调递增关系,是倒 U 型:

帅度
 ↑        ╭──╮
 │      ╭─╯  ╰─╮
 │    ╭─╯      ╰──╮  ← 过了顶点开始往"凶 / 猛 / 糙"跑
 └────────────────────→ 骨相强度

而年龄轴在这个场景里是单调的:少年感的脸 + 已长开的骨架,几乎总比少年感的脸 + 少年骨架更”帅”。先走单调的那条轴,是更安全的第一刀。

实证（2026-08-05，男主「校草」）

轮次改了什么结果
V1原始词块裸跑出图是韩系少年脸。客观缺陷两条:年龄看着 17–18(设定 21)、窄肩细脖(设定 188 修长)
V2按”对标许凯 / 嘉尔”改成浓颜骨相堆满(眉骨投影 / 剑眉 / 锐利下颌 / 深眼窝)实际跑图,创作者确认不理想
V3回到 V1,只加年龄锚与体格锚,五官一个字不动一批即过,创作者与合作者共同定版

V1 的问题从头到尾都在年龄轴和骨架轴上,却被当成颜系轴处理,白走一轮。

操作规则

  1. 收到审美类反馈,先问”哪条轴”再动 prompt——“不够帅 / 不够美 / 差点意思”都不是可执行指令
  2. 默认先试年龄轴:它是单调的,风险最低。写法是改骨骼成熟度和颈肩,不改五官形状
  3. 颜系轴要小步走:每次只加一个骨相词,加完就看。堆满必翻车
  4. 改一轴时冻结其他轴——V3 之所以一次过,是因为它只改了年龄和体格,光、色、构图、发型、唇全部保持 V1 原样
  5. 风格归属 ≠ 客观缺陷:“这张是韩系 / 日系 / 欧美系”是归属判断,不构成必须修的理由;“年龄不对 / 比例不对 / 设定物件没出现”才是客观缺陷。把归属判断当缺陷,是这次白走一轮的根因

反例 / 边界

  • 题材本身就要浓颜时不适用——古装、武侠、硬汉、时尚大片,颜系轴就是主轴,该堆就堆
  • 年龄轴不是万灵药:如果出图的年龄本来就对,这条轴没有空间可挖,该去查光影轴
  • 本律来自男性人像单案例。女性侧是否同构(即”不够美”是否也多半在年龄轴)未验证;女性侧已知有另一条更强的干扰源,见 AI甜妹脸vs复古东方美人_v1

增量：光影轴的可操作项是三件，不是一件（2026-08-20）⚠️

来源：2026-08-20_雨里旧信_东方美人封面四轮复盘_v1（自有作品封面，非比赛，无平台数据）。

本档原把光影轴写成”改光位与对比”。该案观察到头位与碎发遮挡和光位是同一件事——三者共同决定阴影落在骨骼的哪个面上。可操作项应为：

光位（写落点）+ 头位（侧转 / 下巴角度 / 视线高度）+ 遮挡（碎发投影）

近似受控对照（同一 prompt 血脉，五官词块一字未改、骨相词始终为零）：

定妆照（骨相平）采用图（骨相立）
光even soft frontal studio light, no strong shadows侧向光，明暗过渡落在颧骨与下颌
头位正面直立、下巴平头微侧、下巴微收、从睫毛下方看镜头
碎发规整斜掠过脸颊并在颊上投影

骨相的有无完全由光位 + 头位决定，与五官词无关。 这是本档核心主张（“不够美”的病灶常在光影轴而非颜系轴）的女性侧第一个数据点——原档双盲证据与”校草”实证全在男性侧，本档边界条款里”女性侧是否同构未验证”由此得到一次正面观察。

⚠️ 仍是单项目、对照不严格（采用图是连抽 roll 出来的，非刻意控制变量），不升格。

新增反例条款：定妆照 / 服饰参考图必须用平光（要看清领型、盘扣、开衩），那时”平”是正确的。别拿定妆照去判断”骨相够不够”——该案就是这么误判了一轮。
